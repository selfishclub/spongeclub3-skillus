# 상세페이지 진단·수정 (detail-page)

**한 줄:** 상세페이지에서 손님이 망설이는 곳을 찾아 진단서를 내고, 그 진단서대로 원본 PSD를 고쳐 올릴 파일까지 만들어주는 플러그인

## 어떤 플러그인인가요
스킬 두 개가 한 흐름으로 이어져요. 진단 → 수정 → 올리기 → 다시 진단.
진단 스킬이 상세페이지를 보고 「어디서 망설이고 어디서 실망하는지」를 찾아 고칠 순서를 매긴 진단서를 만들고,
수정 스킬이 그 진단서를 읽어서 원본 PSD를 실제로 고쳐요. 포토샵을 스크립트로 조종해서 바꿀 글자만 바꾸니까
굵기·글꼴이 그대로 남아요. 다 고치면 스마트스토어 규격(가로 860px) 조각으로 잘라줘요.

## 뭘 해주나
- 첫 화면 3초 점검, 섹션 지도, 누수 지점, 우선순위 수정 목록을 진단서 한 장(HTML)으로
- 지적마다 [관찰]/[데이터]/[가설] 근거 표시 — 짐작과 사실을 안 섞어요
- 네이버는 클로드가 못 열어서 GoFullPage PDF·휴대폰 캡처·리뷰 엑셀 받는 법까지 알려줘요
- PSD 글자 바꾸기, 섹션 순서 바꾸기, 원본에 없는 안내 섹션을 같은 글꼴로 새로 만들기
- 「5켤레 구성」 같은 사진은 AI 말고 PSD 안의 실제 사진을 찾아 배치해요
- 전·후 비교 페이지와 「진단서 대조표」로 뭐가 반영됐는지 확인
- 860px 조각 + 올리는 순서

## 더 하고 싶은 말
이미 올라가 있는 detail-page-diagnosis 스킬 카드와 같은 진단 스킬이고, 이 플러그인은 거기에 수정 스킬까지 묶은 버전이에요. 진단만 쓰실 분은 스킬 카드로, 고치는 것까지 하실 분은 이 플러그인으로 받으시면 돼요.

저희 발가락 양말 상세로 진단 → 수정 → 올리기 → 재진단까지 한 바퀴 돌려보며 만들었어요.
올리고 나서 다시 진단하니까 상품명에 넣은 「등산」이 상세 문구와 어긋나는 게 그때서야 보였어요.

안 되는 것도 적어둘게요.
- 수정 스킬은 Windows + 포토샵이 있어야 해요. 맥은 아직 안 돼요
- 피그마는 읽기만 돼요(글자 고치기는 사람이). 진단 스킬은 어디서나 돼요
- 포토샵은 2025에서 확인했어요. 다른 버전은 처음 쓸 때 복사본으로 한 번 확인하는 순서를 적어뒀어요

## 설치
클로드 코드에서 두 줄이면 돼요. 첫 줄은 처음 한 번만.

```
/plugin marketplace add selfishclub/spongeclub3-skillus
/plugin install detail-page@skillus
```

플러그인 파일은 원작자 저장소에 있어요. 원작자가 고치면 자동으로 최신판을 받습니다.
