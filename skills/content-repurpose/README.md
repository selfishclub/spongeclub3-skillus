# content-repurpose

**한 줄:** 블로그 글 한 편을 각 채널별로 올릴 수 있게 발행해주고 뉴스레터 한 통으로 묶는 스킬.

## 어떤 스킬인가요
블로그 글 한 편을 오픈 채팅방· 카카오톡 채널·인스타그램·스레드에 나눠 발행하고, 쌓인 글 3~5편을 뉴스레터 한 통으로 묶는 스킬.

## 뭘 해주나
블로그글 한 편을 넣으면 각 채널의 특성에 맞게 글, 필요에 따라 캐러셀을 발행합니다. 
발행한 글을 저장해두고 이것을 나중에 뉴스레터로 만들어줍니다.
