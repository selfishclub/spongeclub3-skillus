# 이 계정의 값 — 틀

> **이 파일을 복사해 `account.md` 로 저장하고 빈칸을 채운다.**
> 규칙은 `SKILL.md` 와 나머지 참조 파일에 있고, 여기에는 **값만** 둔다.
> 주소나 꼬리표가 바뀌면 `account.md` 만 고친다.
>
> `account.md` 가 없으면 스킬이 처음 쓸 때 **채널 주소와 말투를 한 번 묻고** 시작한다.
>
> **말투는 여기 두지 않는다.** 말투 파일(`voice.md` · `tone.md`)이 있으면 스킬이 그걸 읽는다.

## 정기 발행 (선택)

정해 둔 요일 · 주기가 있으면 적는다. 없으면 비워 둔다 — 스킬은 발행 순서만 지킨다.

| 요일 · 주기 | 무엇 |
|---|---|
| [[ 예: 매주 화 ]] | [[ 예: 블로그 새 글 → 인스타 · 오픈 채팅방 ]] |

## 일정표 (선택)

발행 뒤 체크하는 곳이 있으면 적는다. **비우거나 「없음」이면 스킬이 이 단계를 건너뛴다.**

[[ 없음 / 노션 / 구글 캘린더 / 엑셀 / 직접 만든 화면 ]]

## 짧은 링크 (선택)

짧은 링크를 만들어 쓰면 적는다 — 누른 횟수를 세고 목적지로 넘기는 링크. 없으면 비워 둔다.

| | |
|---|---|
| 만드는 곳 | [[ 예: bit.ly / 내 사이트의 링크 장부 ]] |
| 이름 규칙 | [[ 예: 채널-소재 (insta-post01) ]] |
| 밖(카톡방 등)으로도 보낼 수 있나 | [[ 예 / 아니오 ]] |

> 흔한 단축 링크 서비스 주소는 **스팸 필터에 걸리기 쉬워** 뉴스레터 · 메일에는 쓰지 않는 편이 낫다 (`newsletter.md`).
> 내 도메인으로 만드는 짧은 링크는 괜찮다.
