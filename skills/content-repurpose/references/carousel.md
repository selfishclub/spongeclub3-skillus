# 인스타 캐러셀 (**보조**)

> ⚠️ **`spongeclub3-carousel` 이나 `cardnews` 스킬이 있으면 그것을 쓴다.**
> 그쪽이 훨씬 깊다 — 디자인 시스템 · 편집기 · 이미지까지 간다.
> **이 문서는 그 스킬이 없을 때 최소한으로 굴리기 위한 것이다.**
>
> 슬라이드 문구만 다룬다. 디자인·이미지 생성은 이 스킬의 일이 아니다.

## ⚠️ 장수는 단정하지 않는다

**스킬마다 다르게 말한다.** 어느 쪽도 틀리지 않았고, **쓰는 스킬의 기준을 따른다.**

| | 장수 | 근거 |
|---|---|---|
| `cardnews` | **8~12장** | 12장을 넘으면 이탈이 급격히 는다 |
| `spongeclub3-carousel` | **5~6장** | 완주율이 높다 |
| 여기 | **정하지 않는다** | 할 말이 적으면 적게, 많으면 많게 |

**바뀌지 않는 것은 「1장의 역할」과 「마지막 장의 역할」뿐이다.**

## 뼈대


| # | 이 장에서 하는 일 | 규칙 |
|---|---|---|
| **1** | **훅** — 핵심 한 줄 그대로 | **3초 안에 읽혀야 한다** |
| 2 | 어디서 나온 이야기인지 · 왜 지금 | 1장의 약속을 이어받는다 |
| 3 | 근거·방법 ① | |
| 4 | 근거·방법 ② | |
| 5 | 근거·방법 ③ | |
| **6** | **행동 하나** | **1장과 같은 비주얼로** |

**정리 장을 반드시 넣는다.** 마지막 행동 장 **바로 앞**에 내용을 한 장으로 압축한다 —
**사람들이 캡처해서 가져가는 것이 이 한 장**이고, 그게 저장을 만든다.

## 네 가지는 지킨다

- **1장은 두 번 일한다.** **끝까지 안 넘긴 사람에게 2~3일 뒤 첫 장이 다시 노출된다**(re-serve)
- **한 장에 메시지 하나.** 두 개면 둘 다 안 남는다
- **한 장만 스크린샷해도 뜻이 통해야 한다**
- **마지막 장에 행동은 하나.** 「팔로우도 저장도」는 둘 다 안 한다

> **저장·공유가 좋아요보다 3~5배 강하다.** 「예쁘다」가 아니라 **「나중에 다시 볼 것」**으로 만든다.
> 그래서 **한 장짜리 요약**이 저장을 만든다.


## 훅 만들기

> **`threads-writing/references/hooks.md` 같은 훅 자료가 있으면 그쪽을 먼저 본다.**
> 아래는 없을 때 쓰는 최소 목록이다.

**핵심 한 줄이 이미 있으면 그대로 쓴다.** 새로 짓지 않는다.
없을 때만 아래에서 고른다.

| 패턴 | 형태 |
|---|---|
| **자주 받는 질문** | 「○○인데 왜 나만 안 될까요?」 |
| 통증 지목 | 「○○ 하긴 했는데 안 쓰게 되죠」 |
| 자격 해제 | 「○○ 몰라도 됩니다」 |
| 상태 대비 | 「○○도 모르던 △△가 □□한 방법」 |
| 혼동 지목 | 「이름은 비슷한데 역할이 완전히 다릅니다」 |
| 개수 명시 | 「먼저 볼 것 세 가지」 |

**질문형이 가장 안전하고 가장 세다.** 읽는 사람이 자기 얘기로 받고, **결과를 약속하지 않는다.**

**출처 한 줄이 숫자보다 세다.** 「2배」보다 「○○에서 나온 이야기」가 잘 먹힌다.
**근거 없는 수치를 먼저 제안하지 않는다.**

## 캡션

> **검색 쪽은 `reach.md` 의 「인스타는 검색도 된다」를 같이 본다.**
> 캡션 첫 줄 · 대체 텍스트 · 해시태그 3~5개가 거기 있다.

**첫 두 줄이 승부다.** 펼치기 전에 보이는 부분에 **훅과 받는 방법**이 들어가야 한다.

```
{{핵심 한 줄}}

{{어디서 나온 이야기인지 한 줄}}

{{답 두세 줄}}

{{원본으로 가는 안내 한 줄}}

댓글에 「{{키워드}}」 남겨주시면 {{자료}}를 보내드립니다.
{{필요하면 고지 한 줄}}

#{{주제}} #{{주제}} #{{브랜드}}          ← 3~5개. 30개 도배는 끝났다
```

**끝에 질문을 남긴다.** 댓글이 없으면 도달이 멈춘다 —
「시각이 탭을 받고 → 첫 줄이 더 보기를 받고 → **끝의 질문이 댓글을 받고** → 댓글이 도달을 받는다」

**댓글 키워드는 짧고 오타가 안 나는 한글로.** 두세 글자.
「아무 댓글이나」로 하면 진입 장벽은 가장 낮지만 **대상 구분이 안 되고 자동화도 못 건다.**

## CTA — 프로필 링크로 몰지 않는다

**알고리즘이 깎는다.** 도착지가 어디든 **캐러셀의 행동은 댓글**이고, 링크는 DM 안에서 준다.

```
댓글 「키워드」  →  DM 자동응답  →  DM 안에서 링크(꼬리표 붙여서)
```

프로필 링크는 걸어두되 **캡션에서 「프로필 링크 참고」로 몰지 않는다.**

## 이미지가 글을 방해하면 뺀다

배경을 만들었으면 **글자를 얹어 보고 판단한다.** 예쁜데 안 읽히면 실패다.
**캐러셀의 본체는 글이다.**

**밝은 배경에서 안 읽히는 포인트 컬러는 쓰지 않는다.** 형광 계열이 특히 그렇다.
