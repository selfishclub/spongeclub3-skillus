# 채널별 제약 사전

> **문구를 쓰기 전에 읽는다.** 안 읽고 쓰면 반드시 다시 쓴다.
> 2026-09 기준으로 실제로 부딪혀 확인한 것들이다. 플랫폼은 바뀌므로 **막히면 그 자리에서 다시 확인한다.**

## 네이버 블로그

| | |
|---|---|
| **상단메뉴에 외부 링크** | **안 된다.** 카테고리와 기본 메뉴만 배치된다 |
| **외부 링크를 거는 법** | **위젯** — `내메뉴 → 스킨변경 → 꾸미기 설정 → 레이아웃·위젯 설정 → 위젯직접등록` |
| **위젯이 보이는 곳** | **PC 화면만.** 모바일 블로그에는 안 나온다 |
| **블로그 소개글** | **링크가 안 걸린다.** 글자만 들어간다 → 링크는 위젯으로 |
| **반복 문구** | `글쓰기 → 우측 상단 「템플릿」 → 「내 템플릿」 → 「현재 글 추가」`. **글 전체가 저장된다** |
| 모바일 앱 | **템플릿 기능이 없다.** 폰에서 쓰면 「텍스트 대치」로 대신한다 |

### 위젯 글자 수 — 170px 기준

**한 줄에 한글 8자쯤이 안전하다** (좌우 여백 12px씩 빼면 146px, 12px 한글 ≈ 12px/자).

```
word-break:keep-all    없으면 「알려드려 / 요」로 어절이 쪼개진다
<br /> 로 직접 끊기     어디서 넘어갈지 내가 정한다
```

**줄은 글자 수가 아니라 말 덩어리로 끊는다.**
「해본 방법이 왜 / 나에겐」은 「왜」가 앞줄에 붙어 어색하다.
「해본 방법이 / 왜 나에겐 안 맞았는지」가 읽힌다.

**밀리면** ① `<br />` 로 끊기 ② `font-size:11px` ③ `width` 키우기.
**문구를 깎기 전에 줄을 하나 더 쓰는 쪽을 먼저 본다.**

### 위젯 HTML 뼈대

```html
<a target="_blank" rel="noopener noreferrer" href="{{주소}}"
   style="display:block;width:170px;box-sizing:border-box;padding:16px 12px;
          background:{{색}};color:#faf8f5;text-decoration:none;text-align:center;
          word-break:keep-all;">
  <span style="display:block;font-size:16px;font-weight:700;">{{제목}} ↗</span>
  <span style="display:block;margin-top:7px;font-size:12px;line-height:1.6;color:{{연한색}};">
    {{한 줄}}<br />{{한 줄}}</span>
</a>
```

**`font-family` 는 넣지 않는다.** 네이버 편집기가 따옴표를 두 번 이스케이프해서(`&amp;#39;`) 깨진다.
빼면 블로그 폰트를 물려받아 오히려 잘 어울린다.

## 스레드 (Threads)

| | |
|---|---|
| 글자 수 | 한도 **500자** · **실전 50~150자** |
| **알고리즘이 보는 범위** | **첫 150자.** 훅이 여기 없으면 못 읽는다 |
| **결정 구간** | **업로드 후 10분** — 댓글 3+ · 좋아요 20+ 면 추가 노출 |
| 이어 쓰기 | **답글로 다음 편을 잇는다.** 체류시간과 저장률이 올라간다 |
| 링크 | 걸린다. 다만 **링크가 있는 글은 덜 퍼진다** — 본문으로 붙들고 링크는 답글에 |
| 이미지 | 없어도 된다. **글이 주인공인 유일한 채널** |

**「좋아요는 많은데 안 뜬다」는 댓글이 없어서다.**
알고리즘이 **「소비되지만 참여되지 않는 글」**로 분류해 확산을 막는다.
**답을 다 주지 말고 하나를 남긴다.**

> **팔로워가 아닌 사람의 반응이 더 세다.** 추천·검색으로 들어온 사람이 팔로우를 누르면
> 그 글을 **확산 후보로 재분류**한다. 그래서 **처음 보는 사람도 알아들을 만큼** 써야 한다.

## 인스타그램

| | |
|---|---|
| **프로필 링크 유도** | **알고리즘이 깎는다.** 캡션에서 「프로필 링크 참고」로 몰지 않는다 |
| **대신 쓰는 길** | **댓글 → DM → DM 안에서 링크** |
| 이름 필드 | 30자. **검색에 잡힌다.** 비워두면 손해다 |
| 소개 | 150자. 줄바꿈 된다 |
| 링크 | 여러 개 가능. **하나만 두는 편이 낫다** — 여럿이면 아무것도 안 누른다 |
| 스레드 배지 | `프로필 편집 → 아래로 스크롤 → 「Threads 배지 표시」`. **글이 없으면 끈다** |

**DM 자동화** — 사용자가 **먼저 행동했는가**, **24시간 안에 끝나는가**. 이 둘이 정책의 핵심이다.
댓글→DM은 사용자가 먼저 움직이는 구조라 정상 사용에 가깝다. **콜드 DM과 자동 팔로우는 위반이다.**

## 카카오톡 채널 (소식 · 공지)

| | |
|---|---|
| **공지 카드** | **자유 글이 아니다.** 「소식」을 연결하는 자리다. 소식을 먼저 쓴다 |
| **공지 유형** | 리스트형(한 번에 보임) · 스와이프(첫 장만 보임). **소식이 2~3개면 리스트형** |
| **소식 하나에** | **사진과 링크 중 하나만** 넣을 수 있다 |
| **링크 미리보기 카드** | **첫 번째 링크 하나에만** 붙는다 |
| **댓글** | 소식마다 **「댓글 미사용」을 따로** 체크한다 |
| **채팅** | **두 곳에서 꺼야 한다** — 아래 참조 |
| **웰컴메시지** | **무료.** 친구 추가 시 자동 1회. 400자 · 버튼 2개 · 이미지 1장 |
| **소식 발행 시 알림** | **가지 않는다.** 푸시는 유료 메시지(15원)에만 붙는다 |
| 그래서 | **소식은 매번 올릴 값어치가 없다.** 대표작만 올리고 **공지 카드를 갈아 끼운다** |

### ⚠️ 채팅은 두 곳에서 끈다

```
① 채널홈 편집 → 「채팅」 카드      채널홈에 버튼을 보여줄지
② 「채팅」 메뉴 → 채팅 설정 토글    채팅 기능 자체
```

**①만 끄면 프로필의 말풍선 아이콘으로 여전히 채팅이 온다.**
**보이는 것을 끄는 것과 기능을 끄는 것은 다르다.**

### 웰컴메시지 — 등록 시점이 중요하다

> *"웰컴메시지를 신규 등록하더라도 **기존 친구에게는 발송되지 않습니다**"*

**친구가 0명일 때 등록해야 전원이 받는다.** 나중에 등록하면 그전 사람은 영영 못 받는다.
야간(20:55~익일 08:00) 추가 시 웰컴은 **익일 오전 8시**에 나간다.
수신거부 안내는 별도로 나가는 「채널추가 안내메시지」에 자동 포함된다.

### 사업자 정보 미확인 채널의 금지어

**자격 표기가 막힌다.** 「전문의」로 확인됨 — *"사용할 수 없는 문자가 포함되어 있습니다"*.
**자격·직함으로 읽히는 말이 통째로 막힌다.**

**실제로 막힌 것 — 「전문의」** (2026-09, 사업자 미확인 채널).
같이 막힐 만한 말 — 의사 · 한의사 · 변호사 · 세무사 · 원장 · 대표 · 교수 · 박사 ·
진료 · 진단 · 처방 · 병원 · 치료 같은 **직역·행위어**.

**막히지 않은 것** — 과 이름 · 실명 · 가운뎃점 `·` · 마침표.

> **자격을 못 쓰는 자리에서는 신뢰를 만들지 않는다.** 자격이 살아 있는 채널
> (블로그·뉴스레터)의 링크로 넘긴다. **어느 말이 막히는지는 미리보기로 하나씩 확인한다.**
**막히지 않은 것** — 과 이름 · 실명 · 가운뎃점 `·` · 마침표.

> **자격을 못 쓰는 자리에서는 신뢰를 만들지 않는다.** 블로그 링크로 넘긴다.

## 오픈 채팅방

| | |
|---|---|
| **공지** | **글자만.** 링크 미리보기 카드가 **안 붙는다** |
| **일반 메시지** | 카드가 붙는다. 단 **보낼 때 방에 있던 사람만 본다** |
| **이전 대화 보기** | **그런 설정은 없다.** 입장 시점부터만 보인다 |
| **그래서** | **공지가 모두에게 보이는 유일한 자리다** |
| 방 주소에 꼬리표 | **못 붙인다** (카카오 도메인). 공지 안의 링크에 붙인다 |
| 방장만 말하기 | 관리자 설정. **CRM 용도면 반드시 켠다** |
| 참여 프로필 | **만들 때만 정할 수 있다.** 나중에 못 바꾼다 |
| 입퇴장 표시 | **끈다.** 공지가 묻히고, 나가는 것도 다 보인다 |

### 공지 쓰는 법 — **접히면 안 된다**

**「전체 보기」가 뜨면 진 것이다.** 접힌 아래는 안 읽힌다.

**경계는 약 500자, 안전선은 400자.**

실제 사례 둘을 재보니 **줄 수가 아니라 글자 수 기준**이었다.

| | 화면 폭 | 보인 줄 | 보인 글자 |
|---|---|---|---|
| 사례 A | 좁음 (~20자/줄) | 23줄 | **약 460자** |
| 사례 B | 넓음 (~34자/줄) | 14줄 | **약 480자** |

**줄 수는 30 대 19로 크게 다른데 글자 수는 거의 같다** — 화면 폭이 달라도 잘리는 지점이 같다.
카카오 웰컴메시지 한도가 정확히 400자인 것도 같은 단위로 보인다.

```
전체 400자 이내
  핵심            200~250자
  「더 자세한 이야기는」 + 링크
```

**⚠️ 주소도 글자 수에 들어간다.** 긴 주소에 꼬리표까지 붙으면 **60~80자**를 먹으므로
**본문은 320자쯤으로 잡는다.**

> 표본이 둘이라 확정은 아니다. **400자 안에서 끝내면 어느 쪽이든 안 잘린다.**
> 실제와 다르면 이 숫자를 고친다.

**구성**

```
① 이번에 알릴 핵심          두세 줄.  이것만 읽어도 뜻이 통해야 한다
② 「더 자세한 이야기는」 + 블로그 링크   ← 꼭 넣는다
③ 이미지 한 장 (선택)
```

**공지에는 링크 카드가 안 붙으므로 이미지가 유일한 시각 요소다.** 넣을 값어치가 있다.
**일반 메시지에는 안 넣는다** — 블로그 링크 카드가 이미 이미지를 갖고 온다.

**공지의 블로그 링크에는 유입 꼬리표를 붙인다.** 오픈 채팅방에서 온 사람을 세는 유일한 자리다
(방 주소 자체에는 못 붙인다).

### 일반 메시지는 카드가 붙는다

```
공지          카드 없음  ·  전원이 본다        → 상시 안내
일반 메시지    카드 붙음  ·  그때 있던 사람만    → 새 글 알림
```

**둘 다 쓴다.** 공지가 「여기가 뭐 하는 방인가」, 메시지가 「지금 이걸 보라」다.

> **미리보기 카드가 예쁘게 뜨려면 도착 페이지에 `og:image` 가 있어야 한다.**
> 카카오는 **가로로 넓은 비율**(2:1 안팎)에서 잘 나온다. 없으면 회색 빈 카드가 뜨고,
> **한 번 그렇게 캐시되면 주소를 바꾸기 전까지 안 바뀐다** — `publish-check.md` 참조.

> **「이전 대화」가 되는 것은 팀채팅**(「팀 데이터 보관」)이다. 다만 **참여 프로필이 실명 카톡 프로필로 고정**돼
> 익명성을 잃고, 검색 유입과 QR 배포 전략도 같이 잃는다. **모르는 사람이 조용히 받아가는 방**에는 안 맞는다.

## 이메일 뉴스레터

**이미지를 기본 차단하는 메일 앱이 많다.** 이미지만 있으면 스팸 점수도 올라간다 —
**텍스트가 본체, 이미지는 보조.**


| | |
|---|---|
| 여는 사람 | **20~30%.** 카톡보다 훨씬 낮다 |
| 대신 | **길고 개인화된 것**을 보낼 수 있는 유일한 곳 |
| 제목 | **여는 이유의 전부다.** 본문을 아무리 잘 써도 제목에서 끝난다 |
| 첫 줄 | 미리보기에 딸려 나온다. **제목을 반복하지 않는다** |
| 길이 | 스크롤 세 번 안쪽. **한 통에 주제 하나** |
| 링크 | **하나를 크게.** 여러 개면 아무것도 안 눌린다 |
| 발송 주기 | **약속한 대로.** 「한 달에 한 번」이라 했으면 지킨다 |

**블로그와 짝이다.** 블로그에 쓴 것을 정리해 보내는 구조면 새로 쓸 일이 없다.

> **명단은 플랫폼이 못 가져간다.** 계정이 막혀도, 알고리즘이 바뀌어도 남는 유일한 것이다.
> **그래서 다른 채널의 목적지가 대개 여기다.**
