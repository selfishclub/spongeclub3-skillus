# 인스타 캡션

> **슬라이드(이미지)는 이 스킬이 만들지 않는다.** 캐러셀 스킬에 넘긴다 —
> 없으면 **슬라이드 없이 캡션만** 낸다. 몇 장으로 짤지, 장마다 뭘 넣을지는 그쪽 일이다.
>
> **여기는 캡션 글만 다룬다.**

> **검색 쪽은 `reach.md` 의 「인스타는 검색도 된다」를 같이 본다.**
> 대체 텍스트 · 해시태그 고르는 법이 거기 있다.

## 첫 두 줄이 승부다

**펼치기 전에 보이는 부분에 훅과 받는 방법이 들어가야 한다.**

```
{{핵심 한 줄}}

{{어디서 나온 이야기인지 한 줄}}

{{답 두세 줄}}

{{원본으로 가는 안내 한 줄}}

댓글에 「{{키워드}}」 남겨주시면 {{자료}}를 보내드립니다.
{{필요하면 고지 한 줄}}

#{{주제}} #{{주제}} #{{브랜드}}          ← 3~5개. 30개 도배는 끝났다
```

**끝에 질문을 남긴다.** 댓글이 없으면 도달이 멈춘다 —
「시각이 탭을 받고 → 첫 줄이 더 보기를 받고 → **끝의 질문이 댓글을 받고** → 댓글이 도달을 받는다」

**댓글 키워드는 짧고 오타가 안 나는 한글로.** 두세 글자.
「아무 댓글이나」로 하면 진입 장벽은 가장 낮지만 **대상 구분이 안 되고 자동화도 못 건다.**

## 훅 만들기

> **`threads-writing/references/hooks.md` 같은 훅 자료가 있으면 그쪽을 먼저 본다.**
> 아래는 없을 때 쓰는 최소 목록이다.

**핵심 한 줄이 이미 있으면 그대로 쓴다.** 새로 짓지 않는다.
없을 때만 아래에서 고른다.

| 패턴 | 형태 |
|---|---|
| **자주 받는 질문** | 「○○인데 왜 나만 안 될까요?」 |
| 통증 지목 | 「○○ 하긴 했는데 안 쓰게 되죠」 |
| 자격 해제 | 「○○ 몰라도 됩니다」 |
| 상태 대비 | 「○○도 모르던 △△가 □□한 방법」 |
| 혼동 지목 | 「이름은 비슷한데 역할이 완전히 다릅니다」 |
| 개수 명시 | 「먼저 볼 것 세 가지」 |

**질문형이 가장 안전하고 가장 세다.** 읽는 사람이 자기 얘기로 받고, **결과를 약속하지 않는다.**

**출처 한 줄이 숫자보다 세다.** 「2배」보다 「○○에서 나온 이야기」가 잘 먹힌다.
**근거 없는 수치를 먼저 제안하지 않는다.**

## CTA — 프로필 링크로 몰지 않는다

**알고리즘이 깎는다.** 도착지가 어디든 **행동은 댓글**이고, 링크는 DM 안에서 준다.

```
댓글 「키워드」  →  DM 자동응답  →  DM 안에서 링크(꼬리표 붙여서)
```

프로필 링크는 걸어두되 **캡션에서 「프로필 링크 참고」로 몰지 않는다.**

**DM 자동화는 두 가지만 본다** — 사용자가 **먼저 행동했는가**, **24시간 안에 끝나는가**.
댓글→DM 은 사용자가 먼저 움직이는 구조라 정상 사용에 가깝다. **콜드 DM 과 자동 팔로우는 위반이다.**
