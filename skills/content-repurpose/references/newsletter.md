# 뉴스레터 — 모드 B 규격

> STEP 4 모드 B 에서 읽는다. 쌓인 블로그 글 3~5편을 **메일 한 통**으로 묶는다.

## 형식은 「하이브리드」다

| 형식 | 무엇 | 이 스킬에서 |
|---|---|---|
| 큐레이션 | 남의 글 링크 모음 | 쓰지 않는다 |
| 오리지널 | 메일 전용으로 새로 쓴 글 | 쓰지 않는다 |
| **하이브리드** | **짧은 새 글 + 내 글 링크 3~5개** | **이것** |

새로 쓰는 부분은 **관통하는 한 줄과 여는 말**뿐이다. 나머지는 이미 쓴 글을 가리킨다.

---

## 제목과 미리보기는 한 세트

메일함에서 **제목 한 줄 + 미리보기 한 줄**이 같이 보인다. 둘을 따로 쓰지 않는다.

```
제목       여는 이유의 전부다
미리보기    제목을 반복하지 않고 이어서 말한다.  40~90자 · 문장을 끝맺는다
```

**미리보기를 비우면 메일 앱이 본문 첫 줄을 끌어온다** — 대개 「브라우저에서 보기」나
「수신거부」 같은 말이 딸려 나온다. **반드시 채운다.**

**제목 후보는 서로 다른 유형에서 셋** 낸다. 같은 유형 셋은 퇴고본 셋이다.

---

## 본문 구조

```
훅            첫 두 줄.  미리보기 다음에 보이는 자리
관통하는 한 줄   이번 통을 꿰는 말.  「9월에 쓴 글 모음」은 아무도 안 읽는다
글 3~5편       한 편에 3~4줄 + 링크 하나
행동 하나       한 통에 CTA 는 하나다
맺음           사람 냄새 나는 한두 줄
추신 (PS)      두 번째로 많이 읽히는 자리다
```

**길이** — 스크롤 세 번 안쪽. 문단은 1~3문장.
**「당신」 : 「우리」 = 3 : 1.** 보내는 사람 얘기보다 받는 사람 얘기가 많아야 한다.

### 추신에 무엇을 넣나

본문에서 못 한 **가장 가벼운 한 가지**. 다음 통 예고, 답장 유도 질문, 인용 한 줄.
**CTA 를 추신에 한 번 더 넣지 않는다** — 행동이 둘로 보인다.

---

## 링크는 블로그로

| | |
|---|---|
| 원본이 거기 있다 | 인스타·스레드는 잘라낸 것이다 |
| **체류시간이 쌓인다** | 메일에서 온 사람은 읽을 마음으로 온다 |
| 다음 행동이 이미 있다 | 블로그 글 맨 아래에 맺음말이 있다 |
| 마찰이 없다 | 인스타는 앱, 스레드는 계정이 필요할 수 있다 |

**예외는 캐러셀이 본체인 콘텐츠뿐이다.** 그건 인스타로.

---

## 보내는 사람

- **이름은 회사명이 아니라 사람 이름으로.** 사람한테 온 메일을 연다
- **답장 가능한 실제 주소.** `noreply@` 로 보내지 않는다
- **답장률(1~3%)이 가장 저평가된 지표다.** 여는 비율보다 답장이 관계를 보여준다

---

## 주기

- **주 1회 또는 월 1회로 약속하고 지킨다.** 빈도보다 일관성이다
- 「한 달에 한 번」이라 해놓고 세 번 보내면 그때부터 안 연다
- **90일 동안 한 번도 안 연 사람**은 세 통짜리 확인 메일을 보낸 뒤 명단에서 정리한다

---

## 스팸으로 빠지지 않게

```
제목 대문자 · 느낌표 남발        빼기
단축 링크 (bit.ly 등)          원래 주소로
이미지만 있는 메일              텍스트가 60~80% 이상
이미지를 기본 차단하는 앱이 많다    이미지 없이도 뜻이 통하게
```

## 한국에서 다르게 보는 것

원본 스킬(영문)은 미국 기준이다. 옮길 때 이것만 바꾼다.

| 원본 | 한국 |
|---|---|
| 제목 글자 수 (영문 기준) | 한글은 폭이 넓다. **모바일에서 20자 안팎**에서 잘린다 |
| CAN-SPAM | **정보통신망법 제50조** — 제목 앞 `(광고)` 표시, 수신거부 방법, 야간(21~08시) 발송 별도 동의 |
| Gmail · Outlook 기준 | **네이버메일 · 다음메일**도 같이 본다 |
| 발송 도구 예시 | 스티비 · 메일리 등 |

> **`(광고)` 표시가 필요한지는 내용으로 갈린다.** 정보성 뉴스레터면 붙지 않지만,
> 상품·서비스를 알리는 순간 광고성 정보가 된다. 판단이 애매하면 붙이는 쪽이 안전하다.
