# 유튜브 — 영상 · 쇼츠 · 게시물

> STEP 4-5 에서 읽는다. **글을 쓰는 것과 업로드 화면에서 고를 것을 같이 낸다.**
> 유튜브는 올리는 화면에서 고르는 칸이 많고, 거기서 빠뜨린 것은 올린 뒤에 고치기 어렵거나(예: 아동용 여부) 도달이 깎인다.
>
> **숫자는 2026-09 기준이다.** 유튜브는 자주 바꾼다. 안 맞으면 업로드 화면이 맞다.
> `[확인 필요]` 가 붙은 줄은 출처끼리 말이 다르거나 계정마다 다른 것이다 — 올릴 때 한 번 본다.

## 셋 중 무엇을 내나

| | 영상 | 쇼츠 | 게시물(이미지) |
|---|---|---|---|
| 무엇 | 가로(16:9) 긴 영상 | 세로(9:16) · **3분 이하** | 채널 「게시물」 탭 · 구독자 홈 피드에 뜨는 글 + 이미지 |
| 누가 보나 | **검색**으로 오는 사람 · 추천 | 쇼츠 피드를 넘기다 **처음 보는 사람** | **이미 구독한 사람** |
| 이 스킬이 만드는 것 | 제목 · 설명 · 챕터 · 태그 · 고를 것 · 고정 댓글 | 제목 · 설명 · 태그 · 고를 것 · 고정 댓글 | 본문 · 이미지 구성 · (투표) |
| 영상 파일 | **이 스킬은 만들지 않는다** — 있는 영상의 글만 쓴다 | 같음 | 이미지는 캐러셀 스킬 · `carousel.md` |

**영상이 아직 없으면 영상 · 쇼츠 칸은 「영상 나오면」으로 비워 둔다.** 없는 영상의 설명을 먼저 쓰면
영상과 설명이 어긋난다. 게시물은 이미지만 있으면 바로 된다.

**STEP 2 에서 정한다** — 셋 중 무엇을 낼지, 영상이 있는지. 여러 개를 내면 원자를 **각각 다르게** 맡긴다.

## 공통 — 한 번에 외울 것

```
제목          100자까지.  모바일에서는 앞 40자쯤만 보인다 → 검색어 · 핵심을 앞에
설명          5,000자까지.  「더보기」 전에 보이는 건 앞 두세 줄 (약 100~150자)
태그 칸        전부 합쳐 500자.  해시태그와 다른 것이다 — 검색 보조일 뿐 효과는 작다
해시태그        설명(또는 제목)에 #.  설명의 앞 3개가 제목 위에 뜬다
               3~5개가 알맞다.  너무 많이 달면 전부 무시된다 [확인 필요: 15개 · 60개 기준이 출처마다 다름]
링크           주소는 가진 그대로, 글자로 쓴다 (꼬리표 · 짧은 링크는 account.md 에 적은 경우만)
```

**제목 후보는 서로 다른 유형에서 셋** 낸다 — 검색어형(「○○ 하는 법」) · 질문형 · 반전형.
같은 유형 셋은 퇴고본 셋이다.

**썸네일 문구(영상)는 제목을 되풀이하지 않는다.** 제목이 말하지 않은 것 하나를 4~8자로.

**설명 첫 두 줄은 검색 결과와 링크 공유 카드에도 실린다.** 채널 이름 · 인사로 열지 않는다.

## 영상 (가로)

### 글

```
제목 후보 3          100자 안.  검색어 앞에
설명
  ① 첫 두 줄         이 영상이 답하는 것.  검색어 한 번
  ② 본문            맡긴 원자 · 3~6줄
  ③ 원본 링크        「글로 천천히 보시려면」 + 원본 주소
  ④ 다음으로 갈 곳    STEP 5 의 표대로 하나 (명단 · 커뮤니티)
  ⑤ 챕터            아래 규칙
  ⑥ 출처 · 고지       규제 업종이면 account.md 의 문구 · 출처는 원본에 있으면 「출처는 원문에」로 줄여도 된다
  ⑦ 해시태그 3~5개    맨 끝
태그 칸              10~15개 · 500자 안 · 검색어 · 비슷한 말 · 채널 이름
고정 댓글            질문 하나 (답하고 싶은 것) — 원본 링크는 설명에 있으니 여기엔 넣지 않아도 된다
썸네일 문구 후보 3     4~8자 · 제목과 다른 말
```

**챕터(타임스탬프)** — 영상 구간이 있을 때만.

```
0:00 으로 시작한다         없으면 챕터가 안 생긴다
세 개 이상                각 구간 10초 이상
한 줄에 하나               「0:00 여는 말」 모양
```

영상 길이를 모르면 챕터 칸은 「영상 보고 채움」으로 둔다. **시각을 지어내지 않는다.**

### 업로드 화면에서 고를 것 — 체크리스트로 낸다

| 칸 | 무엇을 고르나 | 추천 |
|---|---|---|
| 시청자 (아동용 여부) | 「아동용 아님」 / 「아동용」 | **대부분 「아동용 아님」.** 한 번 고르면 댓글 · 알림 등이 크게 달라진다 |
| 연령 제한 | 필요할 때만 | 대개 없음 |
| 변경되거나 합성된 콘텐츠 (AI 표시) | 실제처럼 보이는 AI 인물 · 장면이 있으면 「예」 | AI 로 만든 사람 · 장소가 실제처럼 보이면 **「예」** |
| 유료 프로모션 | 협찬 · 광고가 있으면 체크 | 없으면 끔 |
| 카테고리 | 교육 · 노하우/스타일 · 인물/블로그 … | 정보 채널이면 **교육** |
| 재생목록 | 연재 이름 | 연재마다 하나 |
| 언어 · 자막 | 영상 언어 · 자동 자막 확인 | 자동 자막은 **고유명사 · 숫자만 고쳐** 둔다 |
| 공개 범위 · 예약 | 공개 / 일부 공개 / 예약 | STEP 6 발행 순서에 맞춰 **예약** |
| 최종 화면 · 카드 | 다음 영상 · 재생목록 · 구독 | 영상에만 있다 (쇼츠는 없음) |
| 댓글 | 켜기 / 검토 후 공개 | 규제 업종이면 **검토 후 공개**를 권한다 |

## 쇼츠 (세로 · 3분 이하)

### 글

```
제목 후보 3          100자 안이지만 화면에 짧게 보인다 → 20자 안쪽 훅
설명                 1~2줄 + 원본 주소 + 해시태그 3~5개
태그 칸              5~10개
고정 댓글            질문 하나 — 쇼츠는 댓글이 도달을 부른다
관련 동영상           이 쇼츠 아래에 걸 긴 영상 하나 (있으면)
```

> ⚠️ **쇼츠 설명 · 댓글 속 링크가 눌리지 않을 수 있다** [확인 필요 — 2023년에 막았다는 안내와 된다는 안내가 섞여 있다].
> 그래서 **「관련 동영상」 칸**이 쇼츠에서 다른 곳으로 보내는 확실한 길이다.
> 긴 영상이 없으면 설명에 주소를 글자로 두되, **행동을 링크에 걸지 않는다** — 「채널 게시물에 원문 주소를 걸어 두었어요」처럼.

**쇼츠의 첫 1초가 제목보다 세다.** 영상 속 첫 자막이 훅이면 제목은 검색어 쪽으로 돌린다.

### 업로드 화면에서 고를 것

| 칸 | 추천 |
|---|---|
| 시청자 (아동용 여부) | 대부분 「아동용 아님」 |
| 변경되거나 합성된 콘텐츠 (AI 표시) | 실제처럼 보이는 AI 장면이면 「예」 — 영상 속 표기와 **둘 다** |
| 관련 동영상 | 긴 영상이 있으면 건다 |
| 사운드 | 음악을 영상에 이미 넣었으면 앱에서 또 넣지 않는다 (두 곡이 겹친다) |
| 카테고리 · 재생목록 | 영상과 같게 |
| 리믹스 허용 | 규제 업종 · 얼굴이 나오는 영상이면 끄는 쪽을 권한다 |

## 게시물 (이미지 · 커뮤니티)

```
이미지            최대 10장 · JPG/PNG · 1:1 정사각 권장 (피드에서 정사각으로 잘린다) · 1080×1080 이상
본문              첫 줄 훅 → 맡긴 원자 2~4줄 → 원본 주소 (게시물 링크는 눌린다)
투표 (선택)        질문 하나 + 보기 2~4개 — 답하기 쉬운 것.  구독자 반응이 다음 소재가 된다
조건              구독자 수 조건은 없다.  스튜디오 「고급 기능」이 켜져 있어야 한다 [확인 필요: 계정마다 다름]
```

> **인스타 캐러셀(4:5)을 그대로 올리면 위아래가 잘린다.** 캐러셀 스킬에 **1:1 판을 따로** 달라고 한다.
> 장수도 다르다 — 인스타는 20장까지, 유튜브 게시물은 10장까지. 핵심 10장으로 줄인다.

**게시물은 이미 온 사람에게 가는 글이다** — 오픈 채팅방 일반 메시지와 비슷한 자리다.
처음 보는 사람을 설득하는 말보다 「이번 주에 새로 올린 것」을 알리는 말이 맞다.

## 규제 업종이면

- 적법성은 여기서 판정하지 않는다 — `account.md` 의 검수 스킬을 **모든 문구가 확정된 뒤 한 번** 부른다 (STEP 7)
- 건강 정보 채널은 유튜브에 **출처 정보 패널** 신청 제도가 있다 (나라 · 자격 조건이 있음) [확인 필요: 한국 적용 여부]
- 설명의 고지 문구는 `account.md` 「고지 문구」가 있으면 그대로 쓴다
