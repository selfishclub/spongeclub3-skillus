# coupang-ad-analysis

**한 줄:** 쿠팡 상품이 하루 얼마를 버는지, 광고 제외키워드 뽑아주기, 목표 ROAS 하한 알기

## 어떤 스킬인가요
쿠팡 매출성장 광고(자동입찰) 시 목표 ROAS를 얼마 이상 둬야 마진이 나오는지 알게 하고,
광고를 하는데 자연판매랑 합쳐서 하루에 얼마를 벌고 있는지, 혹은 얼마를 손해 보고 있는지 알게 하고,
안 해도 되는 키워드에 광고비가 들어가진 않는지 체크하고 제외키워드를 뽑아주는 스킬입니다.

## 뭘 해주나
쿠팡광고에서 광고보고서, 윙에서 판매분석 엑셀 받아서 올리면 돼요. 어디서 어떻게 받는지는 스킬이 순서대로 알려줍니다. 쿠팡 광고 처음이면 그거부터 배우게 돼요.

올리면 손익분기 ROAS부터 계산해주고, 지금 목표로는 개당 얼마 남는지 표로 보여줍니다. 그다음 뺄 키워드를 등급별로 뽑고 쿠팡에 그대로 붙여넣을 목록까지 만들어줘요.

다음 주에 리포트 다시 올리면 지난번에 뺀 게 흑자 키워드까지 죽였는지 확인하고 되살릴 걸 알려줍니다. 순위추적 결과를 같이 주면 이미 1~5위인데 광고 돌리는 낭비도 잡아줘요.

일별기록 엑셀 템플릿도 같이 들어 있어요. 원가랑 쿠폰가만 넣으면 손익분기가 자동으로 나옵니다.
