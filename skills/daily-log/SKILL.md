# daily-log — 날짜별 작업 로그 저장·인출

Claude Code는 모든 세션을 `~/.claude/projects/<프로젝트>/*.jsonl` 에 **자동 기록**한다.
이 스킬은 그 원본을 읽어 **사람이 읽기 좋은 로그**(내 입력 + Claude 답변 + 도구 실행 요약)로 만들어
프로젝트 안 `logs/YYYYMMDD/` 폴더에 저장하고, MD/HTML/PDF로 인출한다.

핵심 스크립트: `scripts/build_log.py` (순수 파이썬, 추가 설치 불필요)

## 언제 이 스킬을 쓰나

- "로그 정리해줘 / 저장해줘", "오늘 로그", "이번 세션 로그만", "전체 로그"
- "작업 로그 PDF(HTML)로 뽑아줘"
- "30분마다 자동으로 로그 저장" (→ 아래 '자동 저장' 참고)

## 실행 방법

항상 **현재 작업 폴더(cwd)** 에서 파이썬 스크립트를 호출한다.

```bash
python ~/.claude/skills/daily-log/scripts/build_log.py [옵션]
```

Windows PowerShell:
```powershell
python "$env:USERPROFILE\.claude\skills\daily-log\scripts\build_log.py" [옵션]
```

### 옵션

| 옵션 | 값 | 뜻 |
|---|---|---|
| `--date` | `today`(기본) / `all` / `YYYYMMDD` | 저장할 날짜 범위 |
| `--session` | `all`(기본) / `latest` | 전체 세션 / 가장 최근 세션만 |
| `--format` | `md,html`(기본) / 여기에 `pdf` 추가 | 출력 형식 (콤마로 여러 개) |
| `--out` | 경로 | 저장 루트 (기본: `<cwd>/logs`) |
| `--cwd` | 경로 | 대상 프로젝트 폴더 (기본: 현재 폴더) |
| `--transcripts-dir` | 경로 | 세션 원본 폴더 직접 지정(자동탐지 실패 시) |

### 사용자 요청 → 명령 매핑

| 사용자가 이렇게 말하면 | 이렇게 실행 |
|---|---|
| "오늘 로그 정리해줘" | `--date today --format md,html` |
| "이번 세션만 저장" | `--session latest --format md,html` |
| "전체 로그 저장" | `--date all --format md,html` |
| "PDF로 뽑아줘" | 위 명령에 `--format md,html,pdf` |
| "HTML로 보여줘" | `--format html` |
| "6월 28일 로그" | `--date 20260628` |
| "D드라이브에 백업" | `--out "D:/backup/logs"` |

실행 후 스크립트가 출력한 **저장 위치와 파일 목록을 사용자에게 그대로 알려준다.**
결과 MD 파일은 마크다운 링크로 클릭 가능하게 안내한다.

## 출력물 종류 (사용자 선택 가능)

- **MD** — 가볍고 편집 쉬움. 기본 저장.
- **HTML** — 브라우저에서 색깔·정렬 예쁘게. 자체 완결(파일 하나) → 그대로 공유 가능.
- **PDF** — Chrome/Edge 헤드리스로 자동 변환 시도.
  - 자동 변환이 실패하면: 생성된 HTML을 브라우저에서 열고 `Ctrl+P → 대상: PDF로 저장`,
    또는 `anthropic-skills:pdf` 스킬로 변환하도록 안내한다.
- **바로 공유** — HTML은 파일 하나로 완결되므로 메신저/메일 첨부로 바로 공유 가능.
  더 예쁜 웹 공유가 필요하면 생성된 MD/HTML을 Artifact 로 올리는 것을 제안한다.

## 자동 저장 (주기적)

이 스크립트 자체는 1회 실행이다. **주기 자동 저장은 내장 `/loop` 스킬과 조합**한다.

- 30분마다: `/loop 30m 로그 정리해줘`
- 1시간마다: `/loop 1h 로그 정리해줘`
- 6시간마다: `/loop 6h 로그 정리해줘`

`/loop` 는 현재 세션이 켜져 있는 동안 지정 간격으로 반복 실행한다.
세션을 꺼도 항상 돌게 하려면 `schedule`(클라우드 예약) 스킬을 안내한다.
사용자가 "자동으로 저장" 을 원하면 위 `/loop` 사용법을 알려주고,
원하는 간격을 물어 해당 명령을 제안한다.

## 동작 원리 (참고)

1. 현재 폴더(cwd)에 해당하는 세션 기록 폴더를 `~/.claude/projects/` 에서 자동 탐지
   (각 .jsonl 안의 `cwd` 값으로 매칭).
2. `user`/`assistant` 메시지를 시간순으로 수집. 사람이 실제 입력한 것과 도구 결과를 구분.
   `thinking`(사고 과정)은 로그에서 제외.
3. 날짜 필터 후 세션별로 묶어 MD/HTML 렌더링.
4. 요청 시 HTML → PDF 변환(브라우저 헤드리스).

## 주의

- 로그에는 대화 전문이 담긴다. 민감 정보가 있으면 저장 위치·공유에 주의하도록 사용자에게 알린다.
- 콘솔 인코딩 문제 방지를 위해 스크립트는 stdout을 UTF-8로 강제한다.
