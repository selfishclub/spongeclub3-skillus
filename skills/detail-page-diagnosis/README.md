# detail-page-diagnosis

**한 줄:** 상세페이지에서 손님이 사기 전에 망설이거나 사고 나서 실망할 만한 곳을 찾아 고칠 순서를 정해주는 스킬

## 어떤 스킬인가요
내 상세페이지나 경쟁사 페이지를 뜯어보는 스킬이에요. 자사몰처럼 열리는 페이지는 주소만 주면 되고, 네이버 스마트스토어는 클로드가 못 열어서 GoFullPage PDF·휴대폰 캡처·리뷰 엑셀을 받아서 봐요. 받는 법도 초보자용으로 알려줘요. 안 팔리는 이유를 확정해주진 않고, 손님이 사기 전에 망설일 만한 곳(답이 숨었거나 말이 서로 다른 곳)과 사고 나서 실망할 만한 약속을 찾아줘요.

## 뭘 해주나
첫 화면 3초 점검, 손님이 사기 전에 망설일 만한 곳(답이 숨었거나 늦게 나오거나 말이 서로 다른 곳)과 사고 나서 실망할 만한 약속을 찾아서, 뭐부터 고칠지(P1~P3)와 고친 뒤 뭘 보면 맞았는지까지 HTML 진단서 한 장으로 줘요. 본 것과 짐작한 것을 [관찰]/[가설]로 나눠 적어요. 리뷰는 전부 읽고 불만 리뷰만 골라 답글을 물어봐요. 경쟁사 페이지면 "가져올 것 / 피할 것 / 이미 이기는 것"까지 나와요.

## 더 하고 싶은 말
써보기 전에 알아두면 좋은 것:
- 네이버 스마트스토어·네이버쇼핑은 클로드가 직접 못 열어요. GoFullPage로 저장한 PDF, 휴대폰 캡처, 리뷰 엑셀을 줘야 해요 (받는 법은 스킬이 알려줘요)
- 안 팔리는 이유를 확정해주진 않아요. 유입이나 가격 같은 페이지 밖 문제는 못 봐요
- 리뷰는 산 사람 얘기라 안 산 사람이 왜 떠났는지는 몰라요. 고친 뒤 결제율이나 리뷰 불만이 줄었는지 봐야 맞았는지 알 수 있어요
