# 누수 유형 여섯 가지

누수 = 구매자의 질문(Q1~Q7)에 페이지가 제때, 보이는 곳에서, 맞게 답하지 못하는 자리.

---

## 빈 답
**어느 섹션도 그 질문에 답하지 않는다.**

- 판별: 섹션 지도에서 Q1~Q7 중 어떤 섹션에도 안 붙은 질문
- 흔한 예: Q6(문제 생기면?)이 통째로 없음 · Q3(왜 여기서?)가 가격 말고는 없음
- 주의: 탭·옵션을 다 열어보기 전에는 빈 답이라고 쓰지 않는다

## 늦은 답
**답은 있는데, 구매자 대부분이 그 전에 떠난다.**

- 판별: 데이터가 있으면 도달률 50% 미만 구간에 있는 Q3·Q4·Q5. 데이터가 없으면 페이지 높이 60% 아래
- 흔한 예: 가장 센 차별점(「최소 수량 없음」「10년째 같은 품질」)이 맨 아래
- 처방 방향: 순서 바꾸기 또는 첫 화면에 한 줄 요약 올리기 (비용: 순서/문구)

## 숨은 답
**답은 있는데, 찾아 들어가야 보인다.**

- 판별: 탭 안 · 옵션 선택창 안 · 이미지 속 작은 글씨 · 표의 엉뚱한 칸 · 약어·기호 표기
- 흔한 예: 수량 단위가 「모델명」 칸에 `10,20,30(○)/13,27(Ⅹ)`로 · 포장비가 옵션 선택 후에만 `+80원`으로 · 무료배송 기준이 결제안내 이미지 안에 · **불만에 대한 설명이 낮은 별점 리뷰의 판매자 답글 안에만** (「안쪽 실은 구조상 일부러 자르지 않습니다」)
- 판매자 답글도 반드시 읽는다. 답글에 이미 좋은 설명이 있으면 처방은 「새로 쓰기」가 아니라 **「답글을 상세로 올리기」** 다
- 왜 새나: 구매자는 모르면 묻지 않고 떠난다. 특히 **돈과 수량 조건**이 숨어 있으면 장바구니에서 놀란다

## 어긋난 답
**페이지 안에서, 또는 들어온 경로와 페이지가 서로 다른 말을 한다.**

- 판별 — 대조할 쌍:
  - 사진 ↔ 옵션 (사진에 있는 색이 옵션에 없다)
  - 제목 ↔ 본문 (「여자 발목양말」인데 본문에 「남자 프리사이즈」)
  - 제목의 약속 ↔ 본문 (제목에 「볼링장추천」인데 본문에 볼링장 이야기가 없다)
  - 사진 ↔ 실제 판매 상품 (사진이 다른 라인 제품)
  - **유입 경로 ↔ 문구** (광고·검색·블로그로 들어온 사람에게 「연락드린 분께만」)
  - **같은 사실의 여러 칸** — 상품명 · 옵션명 · 상품정보 표 · 상세 이미지 속 제품정보 · 포장 사진 (옵션·포장은 「장목」인데 상품정보 표는 「중목양말」 / 제조 표기가 상세 이미지와 상품정보 표에서 다르다)
  - **정도 표현 ↔ 리뷰** — 「보통보다 2배 두꺼움 · 9/9 HEAVY」인데 리뷰에 「얇아요」. **비교 기준이 없으면** 손님마다 다른 것과 비교한다. 이 경우 「얇다」는 모두 등산·운동 맥락(같은 용도 제품과 비교), 「도톰하다」는 일상 맥락(보통 양말과 비교)이었다
- 유입 경로 불일치는 페이지만 봐서는 모른다 → 「이 페이지로 어디서 사람이 오나요?」를 묻는다
- 정도 표현 불일치는 판매자에게 **「무엇과 비교해서요?」** 를 묻고, 처방은 비교 기준을 붙이는 쪽으로 한다 (「일반 양말보다 두꺼운 · 등산양말과 비슷한 두께」)

## 끊긴 길
**다음에 누를 것이 없거나, 멀거나, 엉뚱한 곳으로 간다.**

- 판별: 첫 화면에 버튼 없음 · 고정 버튼 없고 버튼이 맨 아래에만 · 버튼이 목표 행동과 다른 곳으로 감(문의가 목표인데 메인으로) · 버튼 문구가 결과를 말하지 않음(「바로가기」)
- 데이터: 클릭 히트맵에서 버튼 아닌 곳(사진·가격)을 누르면 거기가 「눌러야 할 것 같은 곳」이다

## 잡음
**결정과 상관없는 것이 좋은 자리를 차지한다.**

- 판별: 첫 화면 면적의 절반 이상이 메뉴·카테고리 목록·브랜드 배너 · 같은 말 반복 섹션 · 상품과 무관한 이벤트 배너
- 주의: 쇼핑몰 공통 틀(헤더·카테고리)은 판매자가 상품 하나 때문에 못 바꾸는 경우가 많다 → 비용을 「기능」으로 매기고 P3로 둔다

## 누수가 아닌 것

| 겉보기 | 실제로는 |
|---|---|
| 가격을 가렸다 (「→ ?」) | 채널 추가·문의를 만들려는 **장치**일 수 있다 → 의도 확인 후 「장치가 작동하나」로 본다 |
| 대상을 좁혔다 (「볼링장 전용」) | 좁힌 게 전략이다. 좁힌 대상 밖의 사람이 떠나는 건 누수가 아니다 |
| 페이지가 길다 | 길이 자체는 문제가 아니다. **답이 늦은 게** 문제다 |
| 디자인이 오래돼 보인다 | 취향이다. 구매자 질문에 답을 못 하게 만들 때만(글씨가 안 읽힌다 등) 누수로 쓴다 |
| 상품명에 같은 뜻 키워드를 겹쳐 넣었다 (「파일 … 이중바닥」) | **검색 전략**이다. 단, 서로 **모순되는 속성**(장목과 중목)은 상품정보 표·옵션 같은 칸에서 하나로 맞추게 한다 |
| 치수·수치를 일부러 뺐다 (「발뒤꿈치에서 몇 cm」) | 1~2cm 차이로 항의가 들어와서 뺀 **전략**일 수 있다 → 넣으라고 처방하지 않는다. 대신 그 정보를 대신하는 **표기가 일관적인지** 본다 |
| 상세 끝에 다른 상품 링크·묶음배송 배너 | **함께 담게 하려는 장치**일 수 있다 → 의도 확인 후 「묶음 구매가 생기나」로 본다 |
| 리뷰 불만에 판매자 답글로 응대했다 | 응대는 잘했다. 다만 **설명이 답글에만 있으면** 사기 전 손님은 못 본다 → 숨은 답으로 본다 |
