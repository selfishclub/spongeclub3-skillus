# data — 이메일 없이 답만 받는 법

🔴 **받지 않은 값은 샐 수도 없다.** 리포트를 쓰는 데 이메일·이름·전화는 필요 없다. 그래서 처음부터 안 받는다.

처리방침의 위탁 목록에 AI 서비스가 없다면 특히 그렇다. 답변을 AI 에 넣는 것 자체는 처리방침 문장에 따라 달라지니, **개인을 알아볼 수 있는 값은 넣지 않는 쪽**으로 둔다.

누구에게 보낼지는 **사람이 자기 명단 화면에서 신청 시각으로** 맞춘다.

---

## 세 갈래

| 신청을 받는 곳 | 방법 |
|---|---|
| 구글폼 · 탈리 · 타입폼 등 | **CSV 로 내보내기** → `codes.py csv` |
| 직접 만든 사이트 + Supabase | `codes.py supabase` (서버 키로 필요한 열만) |
| 몇 건뿐 | 답만 대화에 붙여넣기 — 이메일 열을 지우고 |

## ① CSV (구글폼 등)

구글폼 → 응답 → 스프레드시트에서 보기 → 파일 → 다운로드 → CSV.

```
python scripts/codes.py csv <응답.csv> <리포트 폴더>/_codes \
  --time "타임스탬프" \
  --free "지금 가장 물어보고 싶은 것" \
  --keys "Q1 열 이름,Q2 열 이름,Q3 열 이름"
```

- `--keys` 는 **객관식 열 이름**을 쉼표로. 쌍둥이 검사에 쓴다
- `--free` 는 자유서술 열 하나
- `--time` 은 시각 열. **스프레드시트에 보이는 글자 그대로** 쓰므로 명단 화면과 시간대가 같다
- **이름을 주지 않은 열은 읽지 않는다.** 이메일 열은 건드려지지 않는다

🔴 **CSV 파일 자체는 이메일을 담고 있다.** 다 쓰면 지우고, 공개 저장소에 두지 않는다.

열 이름에 쉼표가 들어 있으면 `--keys-file` 로 한 줄에 하나씩 적은 파일을 준다.

## ② Supabase

서버 키가 든 `.env` 경로를 준다. 키 **값**은 대화에 붙이지 않는다.

```
python scripts/codes.py supabase <.env 경로> <리포트 폴더>/_codes \
  --table <표 이름> \
  --time <시각 열> \
  --answers <답이 든 JSON 열> \
  --free <자유서술 키> \
  --keys <객관식 키1,키2,...>
```

- 답이 **JSON 한 열**(`answers`)에 들어 있으면 `--answers` 로 그 열 이름을 준다. 열마다 따로면 `--answers` 를 빼면 `--keys` · `--free` 를 열 이름으로 select 한다
- 읽는 열은 **시각 + 답**뿐이다. `select=*` 를 쓰지 않는다
- 환경 변수 이름: URL 은 `SUPABASE_URL` 또는 `NEXT_PUBLIC_SUPABASE_URL`, 키는 `SUPABASE_SECRET_KEY` 또는 `SUPABASE_SERVICE_ROLE_KEY`
- 🔴 **시각은 명단 화면과 같은 시간대로 바꿔 적는다** (`--tz 9` 가 기본값, 한국). DB 는 대개 UTC 라 그대로 자르면 시간대 차이만큼 어긋나 사람이 엉뚱한 줄을 찾는다. 다른 시간대면 `--tz` 로 맞춘다 (소수 가능)
- 행이 많으면 1000건씩 나눠 받는다
- 답 열이 jsonb 가 아니라 text 여도 읽는다

## ③ 붙여넣기

몇 건이면 명단에서 **시각과 답만** 복사해 붙인다. 이메일 열이 섞여 들어오면 쓰기 전에 알리고 그 값은 어디에도 옮기지 않는다.

쌍둥이 검사를 하려면 **전원의 답**이 필요하다. 한 사람 것만 받았으면 「쌍둥이 검사를 못 했다」를 산출물 머리말에 적는다.

## 나오는 것

```
_codes/codes.json   신청 순서대로 [{no, at, free, answers}]
_codes/twins.md     사람마다 쌍둥이(동률 전부) · 겹침 · 갈리는 칸
```

화면에는 **건수만** 찍는다. 답 내용은 파일에만 쓴다.

🔴 **자유서술에 고객이 직접 적은 이름·연락처는 스크립트가 걸러내지 못한다.** 매칭표를 만들 때 보이면 리포트와 설정 어디에도 옮기지 않는다.

명단이 늘면 다시 돌린다. **번호는 파일(또는 DB 정렬)의 행 순서다.** 스프레드시트를 다시 정렬했으면 번호가 바뀐다. 새로 들어온 사람은 뒤에 붙는다. 이미 쓴 초안 번호는 그대로다.
