# send — 보내기와 기록 단계

초안이 나온 뒤부터 고객이 가두리망에 들어오기까지. **스킬은 보내지 않는다.** 사람이 읽고 고쳐서 자기 메일로 보낸다. 스킬은 그 옆에서 기록하고, 고친 것을 설정으로 돌려보낸다.

단계마다 `setup.md` 와 같은 네 칸.

```
📥 넣는 것 · 🔔 환기 · 💡 추천 · 📤 남는 것
```

---

## 보내기 1 · 누구에게 몇 통을 보낼지 정한다

| | |
|---|---|
| 📥 넣는 것 | `_작성메모.md` 를 보고 사용자가 확인한 것 — **테스트로 넣은 신청** · **같은 사람의 재응시** · 이번에 **보낼 대상**(전원 / 일부) |
| 🔔 환기 | 스킬은 이메일을 모르니 같은 사람인지 판단할 수 없다. 한 사람에게 두 통이 가면 「자동으로 만든 것」이 드러난다. 일부만 보내면 약속(「모든 분께」)과 어긋나는지 한 번 본다 |
| 💡 추천 | 같은 사람이면 **나중에 낸 답**으로 한 통. 명단 확인은 **명단 화면과 같은 시간대의 신청 시각**으로 |
| 📤 남는 것 | `_발송기록.md` 맨 위 「명단 확인」 — 사용자가 확인한 결과만. **이메일 주소는 적지 않는다** |

## 보내기 2 · 메일 제목을 정한다

| | |
|---|---|
| 📥 넣는 것 | 사용자가 쓸 **제목** · 고객이 이미 받은 **확인 메일 제목**(있으면) |
| 🔔 환기 | 확인 메일은 서비스 주소에서, 리포트는 개인 메일에서 나가면 **보낸 사람이 달라 보인다.** 고객이 같은 곳에서 온 메일로 알아보지 못하면 열지 않는다 |
| 💡 추천 | 확인 메일과 **같은 머리말**(예: `[서비스 이름]`) + 고객이 남긴 것을 가리키는 말(예: 「남겨주신 답에 대한 리포트입니다」). 「개인별 리포트 안내」처럼 공지로 읽히는 말은 피한다. **모든 통에 같은 제목** |
| 📤 남는 것 | `_발송기록.md` 「메일 제목」 |

## 보내기 3 · 한 통씩 읽고 고쳐 보낸다

| | |
|---|---|
| 📥 넣는 것 | 사용자가 「N 시작」「N 보냄」이라고 알린다 · **고친 곳**(무엇을 → 무엇으로) · 보낸 판(메일용 판을 썼는지) |
| 🔔 환기 | **고친 곳이 다음 초안을 좋게 만드는 유일한 재료**다. 말로 안 남기면 다음 통에서 같은 곳을 또 고친다. 시각을 안 적으면 「무엇이 줄었나」를 나중에 말하지 못한다 |
| 💡 추천 | 메일에는 **`.메일용.txt` 를 통째로 복사해 붙인다.** 검토용 `.md` 를 붙이면 매칭표와 코드블록이 딸려 간다. 가두리망 링크는 보내기 전에 한 번 눌러 본다 |
| 📤 남는 것 | `_발송기록.md` 한 줄 · 고친 말 → `목소리0층.md` · 판단 → `역할표.md` · 모양 → `리포트틀.md` |

### 시각을 적을 때

**시스템 시계의 시간대를 확인하고 적는다.** 셸에 따라 시간대 이름을 못 읽고 UTC 를 내놓는다. 사용자가 보는 시계와 다르면 바로 고친다.

### `_발송기록.md` 모양

```markdown
# 발송 기록 · [YYYY-MM-DD 초안]

## 명단 확인 (사용자가 명단에서)
- [테스트 행 · 같은 사람 · 이번에 보낼 대상]

메일 제목: [제목]

| # | 시작 | 보냄 | 걸린 분 | 고친 곳 | 설정에 더한 것 |
|---|---|---|---|---|---|

## 무엇이 줄었나
- 리포트 없이(또는 스킬 없이) 한 통: [N분 · 추정/실측]
- 초안을 읽고 고쳐 보내기: [N분 · N통 실측]
```

## 보내기 4 · 무엇이 줄었나 돌아본다

| | |
|---|---|
| 📥 넣는 것 | **스킬 없이 한 통 쓰던 시간** — 잰 적이 없으면 사용자 느낌으로 |
| 🔔 환기 | 기억으로 말한 숫자와 잰 숫자를 섞으면 결과를 믿을 수 없다. **초안을 만드는 시간은 「읽고 보내는 시간」에 들어 있지 않다** — 줄어든 것을 말할 때 같이 밝힌다 |
| 💡 추천 | 추정에는 **「추정」**, 잰 값에는 **「N통 실측」**을 붙인다. 시간보다 **「어디서 새는가」**(예: 메일로 옮기기, 같은 말 고치기)를 한 줄 남기는 게 다음 판에 더 쓸모 있다 |
| 📤 남는 것 | `_발송기록.md` 「무엇이 줄었나」 |

## 보내기 5 · 가두리망에서 이어받는다 (범위 밖 — 환기만)

리포트가 할 일은 고객이 가두리망에 들어오게 하는 데까지다. **그다음은 사용자가 약속한 대로** 해야 관계가 이어진다.

- 리포트에 「거기서 제가 답을 답니다」라고 썼으면 **실제로 답이 달리는지**
- 들어온 고객이 무엇을 물었는지 — 그 질문은 **다음 진단지와 역할표의 재료**다
- 가두리망에 글이 쌓이기 시작하면 `_설정/가두리망.md` 「지금 글이 쌓였나」를 바꾼다. 그때부터 「다른 분들 것도 보입니다」를 써도 된다
