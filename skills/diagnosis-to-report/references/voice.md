# voice — 목소리

**목표는 탐지기 우회가 아니다.** 받는 고객이 **「이 사람이 내 답을 읽고 직접 썼다」고 느끼는 것**이다.

두 층으로 본다. **위층이 아래층을 이긴다.**

```
0층  사용자가 직접 고친 말      _설정/목소리0층.md   ← 사용자의 것
추천 검사  AI 글에서 자주 나는 티   아래 · 사용자가 채택한 것만 쓴다
```

---

## 0층 · 사용자가 직접 고친 말

**다른 사람의 0층을 가져다 쓰지 않는다.** 이 층의 값은 「이 사용자가 실제로 고친 흔적」이라는 데 있다. 짐작해서 넣은 줄은 0층이 아니다.

`_설정/목소리0층.md` 는 세 표로 시작한다. **비어 있어도 된다.**

```markdown
### 쓰지 않는 말
| 쓰지 않는 말 | 대신 / 왜 | 언제 |
|---|---|---|

### 하지 않는 것
| | 왜 | 언제 |
|---|---|---|

### 하는 것
| | 어떻게 | 언제 |
|---|---|---|
```

### 📥 처음 채울 재료 — 사용자에게 받는다

- 사용자가 **직접 쓴 글** 두세 편 — 거기서 자주 쓰는 말끝·호칭·문장 길이를 **보여 주고 맞는지 묻는다**
- AI 초안에서 **매번 고치는 말**
- 고객을 **부르지 말아야 할 말** — 라벨·호칭. 당사자가 불쾌해할 수 있는 말은 사용자만 안다

### 쌓는 법

리포트를 보내기 전에 사용자가 고친 말이 생기면 **날짜와 함께 한 줄.** 「무엇을 → 무엇으로 · 왜」를 **사용자의 말로** 적는다. 스킬이 일반화해서 다른 규칙으로 바꾸지 않는다.

---

## 추천 검사 — 채택한 것만 쓴다

준비 6 에서 보여 주고 사용자가 고른다. 고른 것은 `_설정/리포트틀.md` 「채택한 검사」에 적는다. **안 고른 것은 검사하지 않는다.**

### 리듬

| 추천 검사 | 왜 |
|---|---|
| **한 문장짜리 문단**이 연달아 셋 이상이면 합친다 | 결정타처럼 끊는 문장이 이어지면 광고 카피로 읽힌다 |
| **「~서요.」로 이유를 떼는 문장**을 줄인다 | 말끝이 흐려지고 같은 리듬이 반복된다 |
| **문장 길이**를 섞는다 | 길이가 고르면 기계가 쓴 글로 읽힌다. 가장 효과가 큰 한 가지 |
| **무엇이든 셋으로 묶기**를 줄인다 | 형식적인 삼단은 AI 글의 흔한 버릇이다 |
| **요약으로 닫지** 않는다 | 앞을 되풀이하면 끝이 약해진다. 가두리망 문장으로 닫는다 |

### 표기

| 추천 검사 | 왜 |
|---|---|
| 줄표(—) · 겹낫표(「」)를 메일 본문에서 쓰지 않는다 | 메일에서 어색하게 보이고 문서 말투가 된다. 쉼표·마침표·작은따옴표로 |
| 고객이 쓴 말을 문장 안에 넣을 때 **작은따옴표로 묶는다** | 따옴표 없이 조사를 붙이면 끊겨 읽힌다 (`'처음부터 다시'가 아니라`) |
| 볼드는 최소 | 강조가 많으면 아무것도 강조되지 않는다 |

### 말

| 추천 검사 | 왜 |
|---|---|
| **접속어가 문단마다 규칙적으로** 나오면 뺀다 — 이처럼 · 또한 · 이를 통해 · 따라서 | 한국어 AI 글에서 가장 자주 지목된다 |
| **「핵심은」「중요한 점은」** 반복을 뺀다 | 같은 이유 |
| **강박적 균형**(「A이기도 하고 B이기도 하다」)을 한쪽으로 | 판단을 피하는 글로 읽힌다 |
| **거창한 어휘**(본질적인 · 패러다임 · 여정)를 뺀다 | 한 사람에게 쓰는 편지에 안 맞는다 |
| **위로로 시작하지** 않는다(「뒤처지신 게 아닙니다」) | 관찰이 아니라 판정이 된다 |
| **문턱 낮추는 말**(「부담 갖지 마세요」)을 쓰지 않는다 | 문턱을 낮추면 가치도 같이 낮아진다 |
| **겪지 않은 일을 겪은 것처럼** 쓰지 않는다 | 사람 냄새를 내려고 지어낸 한 줄이 가장 위험하다 |
| **세지 않은 것을 비율로** 쓰지 않는다 | 센 것은 「N명 중 M명」으로 쓰고, 세지 않은 것을 비율로 꾸미지 않는다 |

## 글쓴이가 보이는 자리

관찰과 처방만 있으면 **쓴 사람이 안 보인다.** 추천은 **짐작에 대한 유보 한 줄** — 「답만으로는 알 수 없는 것」을 한 번 인정하는 문장이다. 끝맺음 가까이에 둔다. 쓸지는 사용자에게 묻는다.

```
[답만으로는 알 수 없었던 것]은 모르고 썼습니다. [그 경우 달라질 수 있는 것]은 해보셔야 압니다.
```

## 채우면 안 되는 칸

고객의 직업·가족·최근 일처럼 **확인할 수 없는 사실**은 `[대괄호]` 로 비워 고객이 채우게 하거나 `[확인 필요]`. 틀린 짐작은 빈칸보다 나쁘다 — 「이 사람 나를 모르는구나」가 된다.
