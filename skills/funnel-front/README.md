# funnel-front

**한 줄:** 신청 페이지는 만들었는데 아무도 안 들어올 때, 사람 끌고 오는 앞단 콘텐츠를 통으로 뽑아주는 스킬

## 어떤 스킬인가요
랜딩이나 신청 폼은 만들어놨는데 유입이 없을 때 쓰는 스킬이에요.

앞단 콘텐츠는 설득하는 글이 아니라 "한 번의 클릭, 한 번의 스캔"을 얻는 글입니다. 설득은 신청 페이지가 하니까요. 앞에서 다 설명해버리면 사람들이 "알겠다" 하고 그냥 지나가거든요. 남겨야 눌립니다.

그래서 채널마다 문구를 따로 씁니다. 채널이 달라서가 아니라 사람이 그걸 마주치는 자세가 달라서요. 스레드는 누워서 스크롤하며 관심 0에서 시작하고, 전단은 걸어가며 3초 보고, 커뮤니티는 방장이 지켜보고 있죠. 같은 문구를 세 군데 돌려 쓰면 셋 다 죽습니다.

온라인만 다루는 스킬이 아니라 QR 전단·배너·명함 같은 오프라인 출력물까지 같이 잡는 게 특징이에요.

## 뭘 해주나
신청 페이지 주소 하나만 던지면 페이지를 읽어서 오퍼·마감·수량을 알아서 채우고, 이걸 문서 한 장으로 뽑아줍니다.

· 후킹 문구 세트 — 앵글 5개(증상·오해·비용·대비·제안)
· 스레드 원고 2안 — 서로 다른 각도로
· 커뮤니티 공지문 — 단톡방 / 오픈채팅 / 맘카페·디스코드
· 오프라인 카피와 배치안 — A4 전단 · X배너 · 명함
· 배포 계획 — 어디에, 몇 장, 누구 허락, 언제
· 인쇄 전 체크리스트 + 지금 바로 하실 일

인쇄용 HTML도 같이 나오는데, 진짜 스캔되는 QR이 이미 박혀 있어서 캔바 안 열고 Ctrl+P만 누르면 PDF가 됩니다.

전부 번호가 붙어 있어서 "3-2 배너 문구 다시"라고 하면 그것만 고쳐요. 안 쓰는 채널은 아예 빼고, 주력 채널이 맨 앞으로 옵니다. 스레드 계정 없는 분한테 스레드 원고 주면 그 페이지는 그냥 버려지니까요.
