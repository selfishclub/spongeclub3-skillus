# kakao-lead-nurture

**한 줄:** 카톡 채널에 들어온 사람에게 보낼 메시지 세 통(웰컴·활용·다음 행동)을 카카오 규칙까지 맞춰 짜주는 스킬

## 어떤 스킬인가요
가두리망이 카카오톡 채널일 때 쓰는 스킬이에요. 채널 추가는 들어오는데 그다음에 뭘 보내야 할지 막힐 때, (광고) 표기·수신거부·야간 발송 같은 카카오 규칙이 헷갈릴 때요.

이메일 CRM이랑 사정이 달라요. 폼이 없으니까 웰컴 메시지가 곧 완료 화면이고, 기존 친구한테는 웰컴이 안 나가고, 밤에 추가한 사람은 다음 날 아침에야 받아요. 이걸 모르고 문안만 쓰면 "자료 안 왔어요" 채팅부터 받습니다.

## 뭘 해주나
다섯 개 물어보고 crm-messages.md 한 장을 만들어줘요. 세 통의 역할표, 카톡 형식 그대로의 문안 세 통(제목·본문·버튼·수신거부), 발송 캘린더에 "친구 N명 × 통수" 비용 줄, 관리자센터 세팅 체크리스트(웰컴 등록 → 자동응답 키워드 → 야간 안내 문구 → 기존 친구용 전체 메시지 → 내 폰으로 테스트).

②번 메시지는 "열어보세요"라고 안 하고 선물 안의 문장 하나를 통째로 꺼내 보여주게 시켜요. 열어본 사람만 ③에 반응하더라고요. 팔 게 아직 없으면 ③은 답장 유도형으로 바꿔줍니다.

## 더 하고 싶은 말
2·3회차 과제로 무료 PDF 나눔을 카톡 채널로 약 2주 돌리면서 실제로 나간 문안 세 통이 참고 자료에 그대로 들어 있어요. 6일간 31명 들어오고 4명 나갔는데(13%), 웰컴에서 판매 버튼을 두 번째에 작게 둔 게 이탈을 낮춘 것 같아요.

카톡 채널은 누가 들어왔는지 카카오가 쥐고 있어서 숫자만 보여요. 편한 대신 이름을 알고 싶으면 답장을 유도하는 수밖에 없다는 걸 스킬에 적어뒀어요. 이메일이나 오카방 쓰시는 분은 변형 규칙(STEP 6)만 보셔도 돼요.
