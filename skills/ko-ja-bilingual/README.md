# ko-ja-bilingual

**한 줄:** 한국어로 써 둔 문서에 일본어를 붙이고, 한/일 전환 버튼이 달린 웹페이지(아티팩트)나 16:9 덱으로 만들어 주는 스킬

## 어떤 스킬인가요
일본 팀이랑 같이 일하다 보면 한국어로 정리한 걸 일본어로 한 번 더 만드는 게 매번 일이었어요.
번역만 되면 끝이 아니라 억 원을 百万円으로 바꾸고, 제목을 일본어로 다시 짧게 쓰고, 그걸 또 보기 좋게 얹는 것까지가 세트라서요.
이 스킬은 그 세트를 한 번에 돌리고 결과를 파일 하나로 줍니다. 기본은 일본어로 열리고 오른쪽 아래 버튼(또는 L 키)으로 한국어로 넘어가니까, 일본 쪽에는 그냥 링크만 보내면 되고 나는 토글로 원문과 대조하면서 검토하면 돼요.

## 뭘 해주나
(입력)
마크다운·텍스트, 이미 만든 HTML, docx, PDF, 노션 페이지 다 받아요.
(번역)
문장이 아니라 주장을 옮기는 규칙표가 들어 있어서 단위(억 원→百万円, %p→ポイント), 종결(である체), 미달 표현(실패→원인 귀속)을 일본 보고 관행에 맞춰요.
(출력)
읽는 용도면 claude.ai 아티팩트로 발행해서 링크를 주고, 발표 용도면 16:9 덱 HTML로 저장해서 PDF로 뽑을 수 있어요.
(검증)
한/일 쌍이 빠졌거나 한쪽에만 글이 있거나 언어가 섞인 곳을 스크립트가 잡아서 0건일 때만 넘겨요.

## 더 하고 싶은 말
템플릿·디자인 토큰·레이아웃 레퍼런스가 폴더 안에 다 들어 있어서 이것 하나만 깔면 돌아갑니다.
색은 템플릿 `:root`의 `--green` 하나만 바꾸면 브랜드가 바뀌어요.
방향은 한→일만이고, 일→한이나 텍스트 번역만 원하면 이 스킬이 아니라 그냥 물어보시면 돼요.
일본어가 보통 한국어보다 1.3배쯤 길어져서 덱은 일본어 화면부터 맞추도록 되어 있습니다.
