# 한국어 → 일본어 옮기기 규칙

이미 쓰인 한국어 문서를 옮기는 상황이 전제다. 원문은 손대지 않고(`.x-ko`에 그대로), 일본어는 **번역이 아니라 같은 주장을 일본어로 다시 쓴 것**이어야 한다. 기계 번역 티가 나는 문서는 한국어 원문을 달라는 요청으로 돌아온다.

같은 폴더의 `language.md`(타이포·단위·톤 원칙)를 먼저 읽는다. 여기엔 옮길 때 실제로 틀리는 것만 적는다.

## 원칙 세 가지

1. **주장을 옮긴다, 문장을 옮기지 않는다.** 한국어 액션 타이틀이 12자였는데 일본어로 40자가 됐다면 실패다. 일본어로 다시 짧게 쓴다.
2. **숫자 단위는 일본 관행으로 바꾼다.** 숫자만 바꾸고 단위를 한국식으로 두는 것이 기계 번역의 가장 흔한 표식이다.
3. **실패는 원인에 귀속시킨다.** 한국어의 직설적인 미달 서술은 本社 독자에게 필요 이상으로 강하게 읽힌다. 사실은 같게, 초점은 '누가 못했나'가 아니라 '무엇이 어긋났나'로.

### 종결·톤

| 자리 | 한국어 | 일본어 |
|---|---|---|
| 액션 타이틀 | 명사형 종결 "객단가 +23%, 세트 구성이 견인" | 명사형 유지 「客単価+23%、セット構成が牽引」 |
| 본문 | 명사형 또는 "-다" | だ・である体 |
| 권고 | "~해야 함", "~필요" | 「〜が望ましい」「〜を検討したい」「〜を推奨」 |
| 결론 슬라이드 요청 | "승인 요청" | 「ご承認をお願いしたい」「ご判断いただきたい」 |
| 미달 서술 | "문구 역성장, 재고 배분 실패" | 「文具は在庫配分が想定とずれ、前年割れ」 |

### 그대로 두는 것

- 고유명사(브랜드·제품·인물·지명)와 영문 약어. 한국어 고유명사는 가타카나 표기가 굳어진 것만 바꾼다(서울→ソウル, 카카오→カカオ).
- 한국 고유 개념(설·추석 연휴, 학원, 전세 등)은 원어를 두고 첫 등장에 짧은 보충 「旧正月連休（ソル）」.
- 표의 숫자 자체. 단위·구분자만 손본다(원 단위 → 円 표기 시 환율 적용은 사용자 지시가 있을 때만, 없으면 「約」없이 원 그대로 「ウォン」).

## 헤드라인 줄바꿈

한국어 `<br>` 위치를 그대로 쓰지 않는다. 일본어는 熟語·조사 앞에서 끊기지 않도록 `.x-ja` 안에서 따로 잡는다. 2줄 타이틀은 1줄째에 상황, 2줄째에 판단이 오는 형태가 일본어에서 더 잘 읽힌다.

```html
<h1>
  <span class="x-ja">文具は在庫配分が想定とずれ、<br><span class="grad">前年割れ</span></span>
  <span class="x-ko">문구 역성장,<br><span class="grad">재고 배분이 원인</span></span>
</h1>
```

## 길이

일본어는 같은 내용에서 한국어보다 보통 1.2~1.4배 길어진다. 덱에서는 일본어를 먼저 스테이지에 맞추고, 한국어는 따라오게 한다. 일본어가 넘치면 문장을 자르지 말고 **주장을 줄인다** — 불릿을 3개에서 2개로, 리드를 4줄에서 3줄로.

## 자주 나오는 실수

| 실수 | 고침 |
|---|---|
| 「〜することができます」 남발 | 「〜できる」 |
| 한국어 어순 그대로 「〜に対して〜を行った」 | 동사 하나로 「〜した」 |
| 「非常に」「とても」로 강조 | 숫자로 강조하거나 뺀다 |
| 존댓말(です・ます)과 である체 혼용 | 한 문서에 하나. 보고 자료는 である |
| 億円을 한국식 억 원 감각으로 씀 | 1億円 = 약 10억 원. 단위 환산 여부 확인 |
| 「私たち」 | 보고 자료에서는 「当社」「弊社」「チーム」 |
| 일본어 감각으로 한국어 쉼표 뒤 띄어쓰기를 뺌 (`역성장,문구만`) | 「、」뒤는 안 띄우지만 한국어 `,` 뒤는 띄운다. `.x-ko` 안은 한국어 맞춤법 그대로 |
