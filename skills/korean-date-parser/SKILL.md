# Korean Date Parser — 한국어 자연어 날짜·시간 파서

한국어 문장을 `{ date, time, title, hasDate }` 로 분해하는 **의존성 0** 자바스크립트 모듈이다.
브라우저(`window.CalParse`)·Node(`require`) 양쪽에서 동작한다. 실제 캘린더 앱(i Day)에서
음성 입력·빠른입력에 쓰이며 다듬어졌고, **테스트 39개**가 포함된다.

## 언제 쓰나

사용자가 아래 같은 걸 만들 때 이 파서를 프로젝트에 넣어 준다:
- 캘린더 **빠른입력**("내일 10시 치과")
- **음성으로 일정 등록** (음성 인식 결과의 한글 숫자·붙여쓰기·조사 오류가 핵심 난관)
- **리마인더 / 알림** 자연어 입력
- **가계부** 등에서 "3일 저녁 6시 가족식사" 같은 날짜·시간 뽑기

## 설치 (이 스킬이 하는 일)

1. `parse.js` 를 사용자 프로젝트의 스크립트 폴더(예: `js/` 또는 `lib/`)에 복사한다.
2. 브라우저면 `<script src="js/parse.js"></script>` 로 로드 → 전역 `CalParse` 사용.
   Node면 `const CalParse = require("./parse.js")`.
3. 원하면 `tests/parse.test.cjs` 도 함께 복사해 `node --test` 로 회귀 검증.

## API

```js
CalParse.parse(text, todayYmd)
// text: 한국어 문장 (예: "내일 10시 반에 서현역")
// todayYmd: 오늘 날짜 기준점 "YYYY-MM-DD" (상대 날짜 계산의 기준)
// 반환: { title, date:"YYYY-MM-DD", time:"HH:MM"|null, hasDate:boolean }
```

예:
```js
CalParse.parse("내일 10시 반에 서현역", "2026-07-22")
// → { title:"서현역", date:"2026-07-23", time:"22:30", hasDate:true }
CalParse.parse("다음 주 금요일 3시 발표", "2026-07-22")
// → { title:"발표", date:"2026-07-31", time:"15:00", hasDate:true }
CalParse.parse("치과 예약", "2026-07-22")
// → { title:"치과 예약", date:"2026-07-22", time:null, hasDate:false }
```

## 처리하는 것 (음성 인식 대응이 핵심)

- **상대 날짜**: 오늘/내일/모레, **다음 주 / 다다음 주 / 담주**, (다음 주) X요일, `M월 N일`, `N일`, `M/N`
  (지난 날짜면 자동으로 다음 달/다음 해로 넘김)
- **시간**: `HH:MM`, `N시`, `N시 M분`, `N시 반`, 오전/오후/저녁/밤. **무표기 1~7시는 오후로** 해석("3시"=15:00)
- **한글 숫자(음성)**: "열시 십오분" → 10시 15분, "세시" → 3시
- **한글 숫자+단위 교정**: "삼 번출구" → **3번 출구**, "칠 번출구" → 7번 출구 (번·호·층·동·호선·번지 등).
  "이동" 같은 일반 단어는 안 건드리게 공백 패턴일 때만 변환
- **붙여쓰기**: "내일10시에" → 내일 10시
- **조사 흡수**: 에/에서/에는/엔/의/부터/까지/쯤/경 (음성이 '에'를 '의'로 받아적어도 처리)
- 날짜·시간을 뺀 나머지가 **제목**이 된다

## 주의

- 순수 함수(부작용 없음, 네트워크·DOM 접근 없음). 그대로 복붙해 재사용.
- 시간대는 로컬(`todayYmd` 기준). UTC 필요하면 호출부에서 처리.
- 테스트를 함께 넣고 돌려서 프로젝트 환경에서 통과하는지 확인할 것.
