# lead-form

**한 줄:** 신청 받을 데가 없을 때, 리드가 실제로 쌓이는 그릇을 세워주는 스킬

## 어떤 스킬인가요
프로모션 기획은 끝났는데 정작 신청받을 데가 없을 때 쓰는 스킬이에요.
구글폼으로 대충 받고 있어서 데이터가 흩어진 상태에도 맞고요.

기획은 안 합니다. "그릇"만 만들어요 — 신청 페이지, 리드가 쌓이는 노션 DB,
그 사이를 잇는 저장 엔드포인트까지.

## 뭘 해주나
기획서(PRD)가 있으면 바로, 없으면 다섯 개만 묻고 시작해요.

노션 리드 DB 스키마 · 폼 뼈대 HTML · 토큰이 안 새는 서버리스 함수 ·
채널별 UTM 링크 · 배포 후 눈으로 확인할 스모크 테스트 5항목이 나옵니다.

동의를 체크박스 하나로 안 끝냅니다. 동의한 시각·매체·문구버전까지 남겨요 —
2년 뒤 수신동의 재확인 고지에 "동의한 날짜"를 넣어야 하는데, 그게 없으면
재확인 자체를 못 하거든요.
