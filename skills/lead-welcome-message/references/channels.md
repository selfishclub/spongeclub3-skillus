# 채널별 제약

**2026.09.10 확인.** 사양은 바뀐다. 오래됐으면 쓰기 전에 다시 확인한다.
**확인 안 된 값으로 문안을 설계하지 않는다.** 통 수와 글자 수가 틀리면 발행 직전에 전부 다시 짠다.

## LINE 공식계정

*실제 운영으로 확인한 값이다.*

| | |
|---|---|
| 인사말 | **하나의 메시지 안에 말풍선 5개까지** |
| 말풍선당 | **500자** |
| 붙일 수 있는 것 | 텍스트 · 이미지 · 동영상 · 쿠폰 |
| **붙일 수 없는 것** | **PDF 파일.** 자료는 이미지로 바꾸거나 링크로 준다 |
| 발송 상한 | 인사말은 보통 월 상한에 안 잡힌다. **후속 메시지는 잡힌다** |

**등록 위치** — LINE Official Account Manager → 자동 답변 메시지 → 인사말.
기본으로 들어 있는 「친구 추가해 주셔서 감사합니다」류를 **먼저 지운다.**

**같이 켜는 것** — 응답 메시지(답장 왔을 때) · 키워드 응답(문안에서 약속한 키워드).

**계정 인증은 국가에 묶인다.** 인증 신청 대상 국가가 아니면 「사업자의 국가」 필드를 바꿔도 열리지 않는다.
링크·QR로 들어오는 동선이면 앱 내 검색을 안 거치므로 **인증 없이도 막히지 않는다.** 광고를 돌릴 때 재검토한다.

## 카카오톡 채널

| | |
|---|---|
| 웰컴 메시지 | **최대 400자** · 한 통 |
| 기본 안내 | 채널 추가 시 **채널추가 안내메시지가 먼저** 나가고, 웰컴은 그 뒤에 추가로 나간다 |
| **야간 지연** | **20:55 ~ 익일 08:00 에 추가한 사람은 웰컴을 익일 08:00 에 받는다** |

**야간 지연이 설계를 바꾼다.** 밤에 콘텐츠를 올리면 선물이 아침에 도착한다.
「지금 바로 보내드립니다」라고 쓰면 그 사람에게는 거짓이 된다. **「순서대로 보내드립니다」로 쓴다.**

400자는 LINE의 한 말풍선보다 짧다. **통을 나눌 수 없으므로 역할을 압축해야 한다** —
선물 링크 + 부탁 하나. 「지금 당장 쓸모」는 후속으로 넘긴다.

## 이메일

| | |
|---|---|
| 길이 | 사실상 제한 없음. 대신 **읽히는 길이가 제한**이다 |
| 첨부 | 가능. 다만 **첨부는 스팸 점수를 올린다.** 링크가 안전하다 |
| 도달 | 스팸함이 최대 변수. **첫 발송 전 다른 도메인 계정으로 테스트한다** |
| 수신거부 | **법적으로 필수.** → `compliance.md` |

메일은 **제목이 첫 통의 절반**이다. 본문 설계 전에 제목부터 정한다.

## 인스타그램 DM · 채널

| | |
|---|---|
| 자동화 | 대체로 **외부 도구**가 필요하다 (매니챗 등) |
| 제약 | 플랫폼 정책이 자주 바뀐다. **쓰기 전에 현재 정책을 확인한다** |
| 강점 | 콘텐츠에서 **한 앱 안에서** 이어진다. 이탈이 가장 적다 |

## 채널을 고를 때

**「내가 메시지를 보낼 수 있게 되는가」** 하나만 본다. 그게 안 되면 1차 전환이 아니다.

| 묻는다 | 왜 |
|---|---|
| 고객이 **이미 쓰는** 앱인가 | 새 앱을 깔게 하면 거기서 절반이 빠진다 |
| **자동 웰컴**이 되는가 | 손으로 보내면 24시간 안에 못 보낸다 |
| **답장을 받을 수** 있는가 | 대화가 시작돼야 살아 있는 리드다 |
| 수신거부를 **처리할 수** 있는가 | 못 하면 고지 자체를 못 쓴다 |

**일본 시장이면 LINE이 사실상 기본값이다.** 카톡·문자로는 안 닿는다.
반대로 한국 고객에게 LINE을 시키면 앱부터 깔아야 한다.
