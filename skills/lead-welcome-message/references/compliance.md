# 광고 수신 고지와 거부 처리

**웰컴 메시지에 가격이 들어가는 순간 그건 광고성 정보다.** 「신청 확인」이 아니라 「사세요」에 가까우면 그렇다.

> **법적 요건은 사업 형태에 따라 다르고, 옵트인과 (광고) 표기는 과징금이 있는 영역이다.**
> 이 문서는 실무 체크리스트지 법률 자문이 아니다. **확실치 않으면 전문가에게 확인한다.**
> 그리고 **어느 나라 법이 걸리는지부터** 정한다 — 아래.

## 어느 나라 법인가

**받는 사람이 아니라 보내는 사람 기준으로 먼저 본다.**

| | |
|---|---|
| **한국 사업자가 보낸다** | **정보통신망법.** 영리목적 광고성 정보를 전자적 전송매체로 보낼 때 — 사전 동의 · **(광고) 표기** · 수신거부 방법 안내가 필요하고, **21시~08시**는 별도 동의가 필요하다 |
| 일본 수신자에게 **이메일**을 보낸다 | 特定電子メール法의 옵트인이 **추가로** 걸린다. 대상이 「전자메일」이라 메신저는 원칙적으로 밖이다 |
| 메신저 플랫폼 규약 | 대체로 **친구추가·구독이 수신 승낙**으로 다뤄지고, 이용자는 블록으로 끊을 수 있다 |

**플랫폼 규약을 지켰다고 법을 지킨 게 되지는 않는다.** 친구추가만으로 동의가 끝났다고 보지 말고,
**문구로 한 번 더 밝히는 방식**을 쓴다.

## 메신저에는 체크박스가 없다

웹 폼이 없으면 체크박스를 놓을 자리가 없다. 그럴 땐 **첫 접촉에서 고지하고, 거부 수단을 같은 화면에 둔다.**

**세 가지가 반드시 들어간다** — ① 무엇을 보내는지 ② 거부하는 방법 ③ 언제든 바꿀 수 있다는 것.

```
※お得な情報やキャンペーンのご案内をお送りします。
　ご不要な場合は「配信停止」とご返信ください。いつでも変更できます。
```

```
※ 할인·이벤트 안내를 보내드립니다.
　 원하지 않으시면 "수신거부"라고 답장해 주세요. 언제든 바꾸실 수 있습니다.
```

> **이건 체크박스만큼 강하지 않다.** 「전체 동의」로 묶는 것보다는 낫다는 정도다.
> 폼이 생기면 항목별 체크박스로 바꾼다.

## 약속한 키워드는 반드시 자동응답을 건다

**「수신거부라고 답장하세요」라고 써놓고 자동응답이 없으면 그 약속이 거짓말이 된다.**
표기 흔들림까지 키워드로 등록한다 — `配信停止` `停止` `解除` / `수신거부` `거부` `해지`

```
承知いたしました。
お得な情報のご案内は、これより停止いたします。

ご入国日に合わせたご案内など、
お申し込みに必要なご連絡は引き続きお送りします。

またご希望される場合は「配信再開」とご返信ください。
```

**광고성 발송은 끊고, 거래에 필요한 연락은 남긴다.** 둘은 다른 것이고, 그렇게 안내해야 한다.
안 그러면 결제 확인이나 배송 안내까지 못 보내게 된다.

## 명단에 두 칸을 늘린다

```
표시명 | 가입일 | (수집한 정보) | 광고수신 O/X | 거부일자 | 비고
```

**수신거부는 기록이 있어야 지켜진다.** 머리로 기억하면 다음 발송 때 새어 나간다.

## 어떤 메시지에 (광고) 표기가 필요한가

| 메시지 | 광고성인가 | 표기 |
|---|---|---|
| 선물 전달 · 사용법 안내 | 아니오 | 불필요 |
| 가격·선착순이 섞인 부탁 통 | **회색지대** | 고지 문구로 갈음 |
| 후속 메시지 (약속 회수 + 정보 제공) | 아니오에 가깝게 **쓴다** | 불필요하게 유지 |
| 오픈 안내 · 만료 임박 안내 | **예** | **첫 줄에 (광고) · 끝에 수신거부 방법** |
| 결제 완료 · 발송 · 환불 안내 | 아니오 (거래 안내) | 불필요 |

**후속 메시지를 「아니오에 가깝게 쓴다」가 설계다.** 판매 문구를 넣는 순간 (광고)를 달아야 하고,
그러면 열람률이 떨어진다. 그래서 후속은 **약속 회수와 정보 제공으로 채운다** → `followup.md`

**광고성 메시지의 형식**

```
(광고) 브랜드명

[본문]

수신을 원하지 않으시면 "수신거부"라고 답장해 주세요.
```

**외국어 안내문이라도 (광고) 표기는 보내는 나라의 요건이다.** 현지어로 쓰되 자리를 지킨다.

## 보내는 시각

**21시~08시에는 광고성 메시지를 보내지 않는다.** (한국 기준. 별도 동의가 있으면 예외)

- **자동 웰컴은 이 규제와 무관하다.** 가입 그 순간에만 나간다
- **수동 발송(후속·오픈 안내)만 지키면 된다**
- 한국과 일본은 시차가 없어 시각이 같다. **다른 시간대 고객이면 환산한다**

## 폼이 생기면 — 체크박스

**「전체 동의」 하나로 묶지 않는다. 마케팅은 반드시 따로 뺀다.**

```html
<label>
  <input type="checkbox" name="agree_marketing">
  <span><b>[선택]</b> 할인·이벤트 안내를 받겠습니다
    <small>동의하지 않아도 신청은 그대로 진행됩니다. 언제든 해지할 수 있습니다.</small></span>
</label>
```

- [ ] **선택 항목은 기본 해제.** 미리 체크해 두면 동의로 인정되지 않는다
- [ ] **동의 안 해도 신청이 끝까지 진행**되어야 한다. 막으면 강요가 된다
- [ ] **동의 시각·항목·방침 버전을 저장**한다 — `agree_marketing`, `2026-11-01T12:03:22+09:00`, `terms v0.1`
- [ ] 약관은 **새 창**에서 읽히게 (`target="_blank"`)
- [ ] 수신거부는 **가입과 같은 무게로** — 클릭 한 번, 로그인 없이

**동의를 받았다는 사실보다 「언제, 어느 버전에」가 남아야 한다.** 방침을 고치면 버전이 올라간다.
