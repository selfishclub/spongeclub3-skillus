# (내 이름)의 개인 레이어 — 템플릿

**이 파일을 `my-context.md` 로 복사해서 채운다.** 채우면 스킬이 매번 묻지 않는다.
**모르는 칸은 비워둔다.** ☐ 로 남기면 스킬이 그 칸만 묻는다.

---

## 내 채널

| | |
|---|---|
| 사업체 · 서비스명 | ☐ |
| 가두리망 | ☐ LINE / 카카오톡 채널 / 이메일 / 인스타 DM |
| 계정 ID · 가입 링크 | ☐ |
| 유입 (콘텐츠가 어디서 오나) | ☐ 하나면 간단하다. **둘 이상이면 SKILL.md 「두 채널 문제」를 읽는다** |
| 미끼 (들어오면 주는 것) | ☐ |
| 액션 (내가 받고 싶은 것) | ☐ 하나만 |

**유입이 둘 이상이면 이 표를 채운다.**

| | A에서 온 사람 | B에서 온 사람 |
|---|---|---|
| 기대하고 온 것 | ☐ | ☐ |
| 그게 오는 순서 | ☐번째 | ☐번째 |

## 일정

```
☐  현재 상태
☐  판매 개시일        ← 이 전에는 「신청」이라고 쓰면 안 된다
☐  마감 / 만료일
```

**지금 답장할 이유** — ☐ 기간 한정 / 선착순 ☐명 / 그 외 ☐
*(오픈이 한참 뒤면 기간 한정이 안 먹는다. 자리 수로 바꾼다)*

## 지금 문안이 어디 있나

```
☐ 폴더 경로
```

| 문서 | 무엇 |
|---|---|
| ☐ | 현행 웰컴 |
| ☐ | 현행 후속 |

## 현행 시퀀스

```
1  ☐  선물
2  ☐  받은 느낌
3  ☐  지금 당장 쓸모      ← 가장 자주 빠진다
4  ☐  부탁
D+7 ☐  후속
```

**등록해 둔 자동응답** — ☐ 응답 메시지 / ☐ 키워드 응답 (키워드: ☐)
