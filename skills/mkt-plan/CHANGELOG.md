# Changelog

## v2 — 2026-09-10

인터뷰 설계와 산출물 구조를 다시 짬. 테스트 실행에서 드러난 문제를 기준으로 고침.

### 고친 것
- **질문 2번을 사실 기반으로 교체.** "누가 사면 좋겠어요"(희망) → "고객이 실제로 뭐라고 하던가요"(사실). Real Why를 상상으로 채우던 문제의 원인이었음.
- **증거 유무 문항 추가.** Really 블록이 `O%` 자리표시자로 나가던 문제 해결. 증거가 없으면 무엇을 어떻게 집계할지 적음.
- **재료가 없을 때의 갈래 신설.** 고객 반응을 모르면 기획서 대신 임시안 3개 + 일주일 검증 설계를 냄.
- **콘텐츠 유형을 사용자가 고르게 함.** `구매·신청 → 랜딩페이지` 자동 매핑을 제거. 묻지 않고 랜딩을 내미는 것이 가장 흔한 실패였음.
- **대화 중간 핸드오프 절 추가.** 인터뷰 도중 "뭘 팔지 아직 모르겠다"가 나오면 하던 것을 멈추고 다른 스킬로 넘김. 넘길 스킬이 없으면 직접 처리.
- **기대효과 → 판정 기준.** 근거 없는 예측 수치 대신 볼 지표·기간·접는 기준.
- **아웃풋 무게중심 이동.** 파일 위쪽은 붙여넣을 완성물, 아래쪽은 근거. 체크리스트는 사용자 산출물에서 제외.
- **버린 안 2개와 접은 이유를 남김.** A/B 테스트 재료로 재사용.
- **추측 구간을 `⚠︎ 확인 필요`로 표시.** 확인하는 가장 싼 방법을 한 줄로 같이 적음.
- **5Why 예시를 1개 → 3개로.** 결론이 "신뢰 부족"으로 쏠리는 것을 방지.
- 인터뷰 6턴 → 3턴 (탭 선택 활용).
