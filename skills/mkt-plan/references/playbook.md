# mkt-plan 적용 플레이북

각 마케팅 콘텐츠 유형별로 10단계 중 어떤 단계를 어떻게 집중 적용하는지 정리.

---

## A. 광고 카피 (SNS 광고·배너·검색광고)

**핵심 단계:** Key message → 3WRⓡ → Whom

### 순서
1. **5Why로 Real Why 파악** → 타깃이 진짜 원하는 것/두려워하는 것
2. **Whom으로 트리거 선택** → 6가지 중 이 광고에 맞는 1~2개
3. **3WRⓡ 뼈대 작성** → Why(공감) → What(제안) 2문장
4. **Key message 도구 선택** → 숫자/비교/비유/진심 중 하나로 압축
5. **Brain 체크** → "이 카피를 보고 나서 머릿속에 뭐가 남는가?"

### 산출물 형식
```
[헤드라인] — Key message 도구 적용 (15자 이내 권장)
[서브카피] — Why + What (2~3줄)
[CTA] — 기대효과 암시 ("지금 OO하면 OO됩니다")
[근거라인] — Really (리뷰수/수치/수상실적 등)
```

---

## B. 랜딩페이지 / 상세페이지

**핵심 단계:** Flow → 4MAT → Expectation effect

### 순서
1. **목적 정의** — 이 페이지에서 원하는 단 하나의 행동 (구매/신청/다운로드)
2. **Flow 도식화** — 목적→문제→원인→목표→콘셉트→실행방안 순으로 페이지 구조 설계
3. **4MAT으로 섹션 배치:**
   - Section 1: Why (문제 공감, "이런 거 있지 않으세요?")
   - Section 2: What (솔루션 소개)
   - Section 3: How (작동 방식, 기능)
   - Section 4: If (후기·사례·수치로 기대효과)
4. **Key message로 히어로 카피 작성**
5. **Expectation effect로 클로징** — 구체적 수치 + 행동 유도

### 산출물 형식
```
[히어로 섹션] 콘셉트 한 줄 + 서브카피
[문제 섹션] Why — 타깃의 고통 서술
[솔루션 섹션] What + Really (근거)
[기능 섹션] How — 구체적 작동 방식
[사회적 증거] 후기 / 수치 / 수상
[클로징 CTA] If — "지금 시작하면 OO됩니다" + 버튼
```

## C. SNS 콘텐츠 (인스타그램·블로그·뉴스레터)

**핵심 단계:** Whom → Brain → 3WRⓡ

### 순서
1. **Whom 트리거 선택** — 이 콘텐츠가 퍼지려면 어떤 감정을 자극해야 하나
   - 공유되려면: 허세거리 or 교감거리
   - 저장되려면: 본질(정보) or 핑계거리
   - 댓글 달리려면: 진심 or 교감거리
2. **Brain 확인** — 스크롤 멈추게 할 첫 한 줄 / 첫 이미지 정의
3. **3WRⓡ로 콘텐츠 구성** — Why(공감) → Why so(인사이트) → What(제안/정보) → Really(근거)
4. **Key message로 첫 줄 작성**
5. **Expectation effect로 마무리** — "이걸 하면 어떻게 되는가"로 끝맺음

### 산출물 형식
```
[첫 줄 훅] — 스크롤 멈추게 하는 한 문장 (Key message 도구)
[본문] — Why → Why so → What (3WRⓡ 흐름)
[마무리] — Really + 행동 유도
[해시태그/CTA]
```

---

## D. 브랜드 콘셉트 / 네이밍

**핵심 단계:** 5Why → Whom → Key message

### 순서
1. **5Why** — 이 브랜드가 존재해야 하는 Real Why 파고들기
2. **Dividing** — 시장을 쪼개서 우리만의 빈틈(포지셔닝) 찾기
3. **Whom 트리거** — 이 브랜드가 타깃에게 주는 감정 트리거 선택
4. **콘셉트 한 줄** — "Why니까 What" 구조로
5. **Key message 도구로 네이밍 방향 도출** — 숫자형/비유형/감성형/수사형

### 산출물 형식
```
[브랜드 Why] — 존재 이유 한 문장
[포지셔닝] — 시장에서 우리만의 빈틈
[콘셉트] — 타깃에게 주는 핵심 감정/가치
[네이밍 후보] — 각 Key message 도구별 3개씩
[슬로건 후보] — 3WRⓡ 압축형
```

---

## E. A/B 카피 테스트 기획

**핵심 단계:** Key message (도구별 버전) → Brain → Expectation effect

### 순서
1. 동일한 3WRⓡ 뼈대 위에서 Key message 도구만 바꿔 버전 제작:
   - A안: 숫자형
   - B안: 비교형
   - C안: 진심·감성형
   - D안: 비유·수사형
2. 각 버전별로 Brain 체크 — 버전마다 머릿속에 남는 그림이 다른지 확인
3. Expectation effect로 가설 설정 — "A안은 OO타깃에게 더 반응이 높을 것"
4. 테스트 결과 해석 기준 미리 정의

---

## 기획 결과물 표준 출력 형식

마크다운으로 작성해 `/mnt/user-data/outputs/`에 저장 후 present_files로 전달.
파일명: `mkt-plan_{콘텐츠유형}_{주제}_{YYYYMMDD}.md`

**원칙: 위쪽은 붙여넣는 것, 아래쪽은 왜 그렇게 썼는지.** 사용자는 기획론을 읽으러 온 게 아니다.

```
# [제목]

## 바로 쓰는 것
(유형별 완성물. 위 A~E의 산출물 형식을 그대로 채운다.
 프레임워크 용어 0개. 복사해서 그대로 올릴 수 있는 상태여야 한다.)

## 콘셉트 한 줄
(이 콘텐츠를 보고 머릿속에 남을 한 문장)

---
(여기서부터는 근거. 안 읽어도 되는 부분이다.)

## 왜 이렇게 썼나
- 고객이 한 말: "○○○"  ← 사용자가 준 원문 그대로. 없으면 이 섹션을 쓰지 않는다.
- 진짜 이유: (5Why 결론 한 줄)
- 그래서 이 방향: (한 줄)

⚠︎ **확인 필요** — (추측이 들어간 구간 + 그걸 확인하는 가장 싼 방법 한 줄)
※ 추측을 괄호 안에 숨기지 않는다. 줄을 따로 빼야 사용자 눈에 걸린다. 추측이 없으면 이 줄을 통째로 뺀다.

## 버린 안
- 안 A: (방향 한 줄) → 접은 이유:
- 안 B: (방향 한 줄) → 접은 이유:
(A/B 테스트를 하게 되면 여기서 가져다 쓴다)

## 판정 기준
- 볼 지표:
- 기간/표본:
- 접는 기준:
(사용자가 현재 수치를 준 경우에만 목표 수치를 추가한다. 없으면 지어내지 않는다)

## 뼈대 (참고)
- Why (이런 문제 있잖아요):
- Why so (그건 이것 때문이에요):
- What (그래서 이걸 만들었어요):
- Really (실제로 이런 결과가 있어요):
  ※ 증거가 없으면 O% 같은 자리표시자를 넣지 말고,
    "여기에 무엇이 필요하고 어떻게 구하는지"를 한 줄로 적는다.
```

체크리스트 섹션은 사용자 산출물에 넣지 않는다. framework.md의 10단계 체크는 내가 쓰는 self-check이다.
