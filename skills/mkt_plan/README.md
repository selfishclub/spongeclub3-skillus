# mkt_plan

**한 줄:** 카피를 뽑아주는 스킬이 아니다. "우리 제품 좋아요 + 기능 나열"에서 출발하는 습관을 끊고, 고객이 실제로 한 말에서 출발하게 만드는 스킬이다.

## 어떤 스킬인가요
"우리 제품 좋아요"가 아니라 고객이 실제로 한 말에서 출발해 마케팅 결과물을 만드는 Claude 스킬.
광고 카피, 랜딩·상세페이지, SNS 게시물, 뉴스레터, 브랜드 콘셉트, A/B 테스트 카피를 다룬다.

《기획의 정석》 책의 10단계의 프레임 워크를 차용했다.
sponge-gtm-core, sponge-first-conversion, threads-writing이 함께 설치돼 있으면 경계에서 그쪽으로 넘긴다. 팔 아이템이 아직 없으면 GTM 코어부터, 리드를 모으는 전환 페이지면 그쪽으로, 스레드 본문이면 그쪽으로. 셋 다 없어도 mkt-plan은 그대로 작동한다. 넘길 곳이 없으면 직접 처리한다.

## 뭘 해주나
[왜 만들었나]
대부분의 카피 도구는 제품 설명을 넣으면 그럴듯한 문장을 뱉는다. 문제는 그 문장이 아무 근거 없이 만들어진다는 것이다. "고객이 왜 안 사는가"를 AI가 혼자 상상해서 채우면 결론은 늘 비슷한 곳으로 간다. 신뢰가 없어서, 가격이 비싸서, 잘 몰라서.
mkt-plan은 그 자리를 사용자가 실제로 들은 말로 채운다. 문의 로그 한 줄, DM 한 마디, 반응 없던 게시물 하나면 충분하다. 거기서 진짜 이유를 뽑고, 카피와 페이지 구조를 역산한다.
들은 말이 하나도 없으면 기획서를 쓰지 않는다. 대신 임시안과 함께 일주일 안에 무엇을 누구에게 물어볼지를 준다.

[누가 쓰면 좋은가]
고객이 뭐라고 하는지는 아는데, 그걸 어떻게 카피로 바꿔야 할지 모르는 사람.
혼자 파는 사람 — 반응을 직접 듣지만 그게 기획 재료인 줄 모르는 경우
마케팅을 배우는 사람 — 제품 설명은 쓰지만 전부 자기 자랑이 되는 경우
팀·에이전시 — 자료는 많은데 어디까지가 근거고 어디부터가 상상인지 섞여 있는 경우

## 더 하고 싶은 말
[쓰는 법]
그냥 말하면 된다. 
- 상세페이지 카피 좀 써줘. 반려견 수제간식 파는데
- 장바구니까지는 오는데 결제를 안 해
- 이 카피 왜 안 먹히는지 모르겠어

그러면 세 가지를 묻는다.
- 무엇을 파는지, 누가 사는지 (첫 메시지에 있으면 건너뜀)
- 고객이 실제로 뭐라고 하던가요 — 안 산 사람의 말 / 최근에 산 사람의 이유 / 반응 없던 것, 아는 것 하나만
- 진짜 이유 확인 + 오늘 뭘 만들지 + 지금 가진 증거

2번이 전부다. 여기에 실제 문장 하나를 넣느냐 아니냐로 결과물의 질이 갈린다.
