# parenting-community-scout

**한 줄:** 1차 전환 페이지 만들어놓고 뿌릴 데 없을 때, 맘카페·육아 단톡방 찾아서 진입 메시지까지 뽑는 스킬

## 어떤 스킬인가요
페이지는 만들었는데 팔로워가 적어서 아무도 안 들어올 때 쓰는 스킬이에요. 육아 커뮤니티는 이미 개월수별로 사람들이 모여 있으니까, 그 방을 찾아 들어가는 걸 도와줍니다. 방 이름을 지어내지는 않아요 — 검색할 키워드랑 채울 표를 주고, 실제로 찾는 건 본인이 합니다. 오픈카톡은 앱 안에서만 검색되니까 어차피 AI가 대신 못 해요.

## 뭘 해주나
검색어를 4축(정체성·개월수·지역·주제)으로 뽑아주고, 찾은 방을 4유형으로 나눠서 유형별로 다른 진입 메시지를 써줘요. 민폐 게이트 5문항을 통과 못 한 방에는 메시지를 아예 안 써주고, 조리원 동기방이나 어린이집 학부모방은 처음부터 가지 말라고 막습니다. 복붙도 막아요 — 육아 단톡방은 같은 사람이 여러 방에 있어서 같은 글이 두 번 보이면 바로 들키거든요.

## 더 하고 싶은 말
아빠 콘텐츠를 엄마 방에 뿌릴 때가 특히 재밌어요. 링크 누르는 사람(엄마)과 실제로 쓰는 사람(아빠)이 달라서, 혜택을 엄마한테 써야 하거든요. "엄마가 얻는 건 아빠 육아 정보가 아니라 자기 시간"이라는 게 핵심입니다. 테스트해보니 스킬 없이 하면 "남편분께 링크만 보내주셔도 돼요" 문장을 썼다가 광고 같다며 스스로 지워버리더라고요.

같은 상황 4개로 스킬 쓴 쪽/안 쓴 쪽을 비교해봤는데, 안 쓴 쪽은 없는 커뮤니티 이름을 지어내거나 조리원 동기방 글을 그냥 써주더라고요. 육아 쪽으로 1차 전환 페이지 만드신 분들한테 추천합니다.
