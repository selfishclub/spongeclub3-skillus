# 이거, 보내도 돼? (`send-check-kr`)

**문자·알림톡·상세페이지·이벤트·SNS를 내보내기 전에, 한국 광고법에 걸릴 데를 짚고 → 통과되게 고쳐주고 써주는 Claude 스킬.**

알림톡은 보내기 전에 템플릿을 **등록·검수**받아야 하고, 반려는 그 검수 단계에서 납니다. 급하게 등록·발송해야 하는데 반려되면 늦죠. 이 스킬은 **등록·발송 전에** 위반 소지를 미리 훑고, 거기서 멈추지 않고 **안전한 문구로 다시 써주고, 통과 템플릿까지** 만들어줍니다.

## 왜 필요한가

마케팅을 하면 결국 고객에게 무언가를 **내보냅니다.** 문자, 알림톡, 상세페이지, 이벤트, SNS. 그런데 "이거 보내도 되는지"를 아무도 제대로 안 알려줘요. 그래서 대부분 감으로 보냅니다.

- 광고성인데 동의 없이 → 정통망법 위반
- 동의를 필수에 묶어 받으면 → 개인정보보호법 위반
- 식품인데 "면역·효능" 쓰면 → 식약처 단속
- 알림톡에 광고 한 줄 섞이면 → 검수 반려로 아예 못 나감

변호사에게 물어볼 일도 아니고, 그냥 물어보면 두루뭉술하거나 틀린 확신을 줍니다. 법무팀 없는 **1인·초보 사업자에게는 작은 법무팀**이 됩니다.

## 전제 — 참고용이고, 보낼지는 자기 선택

솔라피 같은 검수도 **검수자에 따라 통과가 갈립니다.** 그래서 이 판정은 "절대 기준"이 아니라 **참고**입니다. 솔직히 이 법령들을 전부 다 지키려 들면 메시지를 거의 못 보냅니다. 이 스킬은 "무조건 하지 마"라고 막는 도구가 아니라, **리스크가 어디에 얼마나 있는지 보여주는** 도구입니다. **보낼지 말지는 사용자 본인의 선택입니다.**

**이럴 때 쓰세요** — 시간 여유 없이 당장 보내야 하는데 반려되면 안 될 때 / 지금은 통과돼도 나중에 문제될 소지를 미리 알고 싶을 때.

## 무엇을 하나

판정만 하지 않습니다. **고쳐주고, 써줍니다.**

### ① 위반 소지 점검
광고물을 던지면 🔴위험 / 🟠발송막힘 / 🟡회색 / 🟢괜찮음 + 근거 조항 + 빠진 표기를 줍니다.

### ② 위험 문구 리라이트
막기만 하지 않아요. **규정을 지키면서 살아있는 카피로 다시** 써줍니다. (효능→성분 사실, 광고→정보성, 이중가격→정직한 표기)

### ③ 통과 템플릿 작성
목적(접수·발표·배송·오픈)만 말하면 **검수 통과 잘 되는 완성 템플릿**을 정보성/광고성 버전으로 줍니다. 알림톡은 첫 줄에 발송 계기 고정문구까지.

### ④ 채널 라우팅
"이거 어디로 보내?" → 메시지 성격과 대상을 보고 **알림톡 / 브랜드메시지 / 문자 중 어디로, 왜, 무슨 조건**인지 짚어줍니다.

### ⑤ 발송 전 최종 체크리스트
보내기 직전 원클릭 점검 — 동의 대상 / (광고) 표기 / 무료 수신거부 / 야간 / 업종 표현 / 신고번호.

### (+) 카카오 알림톡 검수 통과·반려 대응
반려 사유를 던지면 **왜 반려됐고 어떻게 고치면 통과되는지** 짚어줍니다.

## 쓰는 법 · 예시

**점검**
```
이거 보내도 돼? "면역 챙기는 제철 감귤! 지금 사전예약하면 3kg값에 5kg → [스토어]"
→ 🔴 위험 — "면역"(식품표시광고법) + 광고성 전송(정통망법). 고칠 문구까지.
```

**리라이트**
```
이 문구 규정 맞게 고쳐줘: "면역 챙기는 제철 감귤"
→ "비타민C 가득한 제철 감귤, 새콤달콤" (🟢) + 왜 안전한지
```

**통과 템플릿 작성**
```
당첨 안내 알림톡 써줘 (무료 증정 이벤트 응모자 중 당첨자에게)
→ 첫 줄 "응모하신…" 고정문구 + 정보성만 담은 통과 템플릿
```

**채널 라우팅**
```
이 사전예약 안내 어디로 보내?
→ 광고성이라 알림톡 ✕. 채널 친구면 브랜드메시지, 동의자면 문자. 조건까지.
```

**발송 전 체크**
```
이거 보내기 전에 체크리스트 좀
→ 동의·(광고)·수신거부·야간·신고번호 원클릭 점검
```

## 판정이 보는 것 — 광고법 5개 층

광고 하나가 여러 법에 동시에 걸릴 수 있어, 다섯 층을 다 봅니다.

| 층 | 법 | 뭘 보나 |
|---|---|---|
| 1 모든 광고 공통 | 표시·광고의 공정화법 제3조 | 거짓·과장 / 기만 / 부당비교 / 비방 |
| 2 보내는 방식 | 정보통신망법 제50조 | 사전 동의·(광고) 표기·수신거부·야간 별도동의 |
| 3 파는 페이지 | 전자상거래법 | 사업자 정보·통신판매 신고번호·청약철회 7일 |
| 4 업종별 | 식품표시광고법·국민건강증진법 등 | 식품·건기식·의료·주류·경품·금융 |
| 5 개인정보 동의 | 개인정보보호법 제22조 | 마케팅 동의 분리·빈칸=미동의 |

## 리스크 등급

적발 확률은 아무도 못 맞히므로 "넌 작으니 괜찮아"라고 하지 않습니다. **다운사이드(걸리면 얼마나 아픈가) + 적발 방식**으로 매깁니다.

- 🔴 **규모 무관 지금 고쳐라** — 판매중지·형사 등 손실 크고 위반 명백 (식품 효능·의료 무심의·주류 음주권장)
- 🟠 **발송 자체가 막힘** — 검수 반려로 아예 못 나감 (알림톡에 광고 섞기)
- 🟡 **회색** — 통과는 상황, 걸리면 이 정도. 확률은 안 맞히고 다운사이드만 알려주고 선택은 사용자
- 🟢 **괜찮음**

## 범위

**포함**: 부당광고·전송규제·판매페이지 표시의무·업종별(식품·주류·경품 등)·개인정보 동의 / 리라이트·통과 템플릿·채널 라우팅·발송 전 체크리스트·알림톡 검수 대응

**제외**(광고법이 아니라 뺌): 카카오 비즈니스 인증·마스터 변경, AI 이미지 폰트, 저작권·상표·초상권 — 넣으면 스킬이 잡탕이 됩니다.
