# 카카오 알림톡 검수 통과 / 반려 대응

> 알림톡 템플릿을 **한 번에 승인**받게 쓰거나, **반려 사유를 읽고 고칠** 때. 검수 주체는 카카오, 2~3영업일 소요.
> 기준일 2026-09. 광고성은 알림톡으로 못 보낸다 → 브랜드메시지(옛 친구톡)로.

## 통과 3원칙
1. **정보성만.** 할인·이벤트·구매유도·혜택 홍보는 반려. (신제품·세일 안내 ✕)
2. **수신자 액션 기반임이 메시지 안에 드러나야.** 카카오는 "이 사람이 무슨 행동을 해서 이 톡을 받는가"를 본다. **발송 계기를 고정 문구로 첫 줄에** 넣는다 — 예: "응모하신", "참여하신", "가입하신", "주문하신", "예약하신", "문의하신".
3. **변수만으로 이뤄지지 않기.** `#{변수}`는 쓰되, 변수뿐인 메시지/버튼·변수 오류·치환값이 많아 의미 파악이 어려우면 반려. 고정 안내문 + 최소 변수.

## 자주 나오는 반려 사유 → 대응
- **"수신 대상/발송 계기가 불명확"** → 첫 줄에 "○○에서 ○○하신 고객님께 안내드립니다" 식 고정 문구 추가 (이번 오트제주 케이스가 이것)
- **"광고성 내용 포함"** → 가격·할인·구매링크·판촉 문구 제거. 정보성만 남기고, 홍보는 브랜드메시지로 분리
- **"혜택(무료체험·쿠폰·포인트)을 조건으로 개인정보 등록 등 특정 행위 유도"** → 유도 문구 제거
- **"변수 오류/변수로만 구성"** → 고정 안내문을 채우고 변수는 이름·일자 등 최소로

## 통과 잘 되는 템플릿 골격
```
[브랜드] (발송계기 고정문구) + (안내 제목)

(○○에서 ○○하신) #{성함}님, (정보성 안내 본문).

(필요 시 수집·확인 요청: 배송/예약/결제 등 거래 관련 정보)

(주의·일정 안내 등 정보성 문구)
[브랜드] 드림.
```
- 가격·할인·"지금 구매"·판매 링크 ✕ (있으면 광고성 → 알림톡 반려)
- 발송 계기(응모/주문/예약 등)를 문구로 명시 ← 반려 1순위 예방

## 검수 의견(요청문) 써주기

알림톡은 솔라피 등 대행사를 거쳐 등록하고, 템플릿을 낼 때 **검수 담당자에게 보내는 "검수 의견/요청문"**을 같이 쓸 수 있다(솔라피의 '검수 요청 의견' 칸 등). 이걸 잘 쓰면 승인 확률이 올라간다. 사용자가 템플릿을 등록한다고 하면 이 요청문도 같이 써준다.

**검수 의견에 꼭 담을 것:**
- **발송 대상** — 누구에게 가는가 (예: 자사 이벤트 페이지에서 직접 신청·응모·구매한 고객)
- **발송 계기/시점** — 어떤 행동 뒤에 나가는가 (응모 접수 / 주문 / 예약 등)
- **정보성 근거** — 광고·판매·할인 등 영리성 내용 없음을 명시
- **발송 계기 고정문구** — 메시지 안에 "신청하신/주문하신…"이 들어있음을 언급

**골격:**
```
본 메시지는 [자사 페이지/서비스]에서 [행동:신청·주문·예약]한 고객에게
[계기·시점]에 [내용:접수확인·발표안내·배송안내]을 전달하는 정보성 메시지입니다.
광고·판매·할인 등 영리성 내용은 포함되어 있지 않으며, 수신 대상은 본인이 [행동]한
고객입니다(발송 계기 문구 "[○○하신]" 포함). 문의는 자사 채널 채팅으로 안내합니다.
```

## 반려당했을 때 순서
1. 반려 사유 문구를 그대로 읽고 위 표에서 유형 매칭
2. 해당 부분만 수정 (문단 순서 조정·고정문구 추가·광고 문구 제거)
3. 재검수 요청. 심사자에 따라 편차가 있으니, 반복 반려 시 문단 순서를 바꾸거나 검수 담당자에게 서비스 성격을 설명하는 요청문을 함께 전달
4. **광고성이 본질이면** 알림톡을 포기하고 **브랜드메시지**로 (채널 친구/동의자 대상, (광고) 표기)
