## 카카오 메시지 3종 정리 (2026 기준 · 용어 주의)

> "플러스친구/플친"은 **옛 이름**이다. 2019년 **카카오톡 채널**로 개명됐고, 광고용 "친구톡"은 2026.1.1 **브랜드메시지**로 대체됐다. 사용자가 "플친으로 광고 보내도 되지?"라고 하면 → "지금은 카카오 채널의 브랜드메시지"라고 바로잡아준다.

- **알림톡 = 정보성 전용.** 채널 추가 안 한 사람에게도 전화번호로 발송 가능. 주문·배송·예약·공지 등. **광고 문구가 일부라도 섞이면 발송 불가/반려.** 시간 제한 없음.
- **브랜드메시지(옛 친구톡) = 광고성 가능.**
  - **채널 친구**(채널 추가자) → 즉시 발송 가능 (채널 추가 = 수신동의 간주)
  - **비(非)친구** → 마케팅 수신동의 확인 + 사전 승인 거치면 발송 가능 (2026 도입)
  - (광고) 표기 + 무료 수신거부 필수
  - **카카오 광고성 발송 가능 시간: 08:00~20:50** (카카오 정책 — 정통망법 야간 21~08보다 더 엄격하니 이 시간 기준으로 안내)
- **채널 자체(카카오톡 채널)** = 비즈니스 채널. 알림톡·브랜드메시지의 발신 주체.

즉 효희 님 표현으로 "플친 광고"는 → **"카카오 채널 브랜드메시지 (친구 또는 동의자 대상, 08:00~20:50, (광고)·수신거부 표기)"** 로 정리된다.

## 자주 나오는 판정
- "광고 문구인데 알림톡으로 보내고 싶다" → ✕. 브랜드메시지·문자(동의자)·채널친구로 안내
- "정보성인데 혜택 한 줄 넣고 싶다" → 넣는 순간 전체 광고성. 넣지 말거나 채널을 바꿔라
- "응모자 명단(무료 이벤트)에 판매 광고 보내도 되나" → 무료 응모는 거래 아님 → 거래관계 예외 불가 → 마케팅 동의 없으면 ✕. 채널 추가 등으로 재동의 필요
