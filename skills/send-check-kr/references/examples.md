# 판정 예시

> 산출 형식을 보여주는 견본. 실제 판정은 입력에 맞춰 조정.

## 예시 1 — 식품 광고 문자 (효능 표현)
입력: "[○○농장] 면역력 쑥! 감기 예방 감귤, 지금 주문하면 20% 할인 → [링크]" / 문자로 전 고객에게

```
【판정】 🔴 위험

【걸리는 곳】
- "면역력·감기 예방" — 근거: 식품표시광고법 제8조 — 일반식품의 효능·질병예방 표현(매체 불문)
- 광고성 전송 — 근거: 정통망법 제50조 — 사전 마케팅 동의자에게만 가능
- "20% 할인" 구매유도 → 광고성 확정

【빠진 필수 표기】
- (광고) 표기 · 무료 수신거부 · 전송자 연락처

【이렇게 고치면】
- "면역력 쑥/감기 예방" → "비타민C 가득한 제철 감귤, 새콤달콤"
- 마케팅 동의자에게만 발송 + 맨 앞 (광고) + 끝에 무료 수신거부

【확인 필요】
- 식품 효능 표현은 식약처 부당광고 기준 확인 권장

※ 참고용 사전 점검이며 법률 자문이 아닙니다.
```

## 예시 2 — 접수 확인 문자
입력: "무료 응모가 접수됐어요. 9/13 추첨 결과 문자로 안내드릴게요." / 응모자에게

```
【판정】 🟢 괜찮음
- 본인이 신청한 건 안내 = 정보성(정통망법 제50조 광고성 아님). 동의 불필요·야간 무관·알림톡 가능
- 단, 효능 단어(면역 등) 없음 확인됨 → 식품법도 무관
※ 참고용 사전 점검이며 법률 자문이 아닙니다.
```

## 예시 3 — 경품 이벤트 안
입력: "선착순 100명 추첨! 아이패드 드려요" 배너

```
【판정】 🟡 주의
【걸리는 곳】
- 경품 가액 상한: 옛 3%·2천만원 규제는 2016년 폐지 → 한도 위반은 아님
- "선착순 100명 추첨"은 선착순과 추첨이 섞여 방식이 모호 → 기만·부당광고 소지(표시광고법 제3조)
【이렇게 고치면】
- 방식을 명확히: "○월○일 추첨 100명" 또는 "선착순 100명" 중 하나로, 발표일·당첨자 수 정확 고지
※ 참고용 사전 점검이며 법률 자문이 아닙니다.
```
