# 근거 법령 지도

> 판정마다 여기서 조항을 인용한다. 기준일 표기 필수. 법·정책은 바뀌므로 오래됐다 싶으면 최신 확인.
> 기준일: 2026-09 (정통망법 현행 · 방통위/KISA 「불법스팸 안내서」 제7차 개정본 2026.03 · 카카오 정책 개편 2026.01.01)

## 표시·광고의 공정화에 관한 법률 (공정위 소관) — 모든 광고 공통
- **제3조 부당한 표시·광고 금지**, 4유형:
  - 거짓·과장: 사실과 다르거나 지나치게 부풀림
  - 기만: 중요한 사실을 은폐·축소
  - 부당비교: 기준·객관 근거 없이 자기 것이 우량·유리하다고 비교
  - 비방: 근거 없이 타 사업자·상품을 깎아내림
- 위반 시 공정위 시정명령·과징금·형사처벌 가능
- 출처: 국가법령정보센터 「표시·광고의 공정화에 관한 법률」

## 정보통신망법 제50조 (영리목적 광고성 정보 전송 제한) — 전송 방식
- 제1항: 광고성 정보 전송은 **사전 수신동의** 필요
- 제3항: **21:00~08:00** 광고 전송은 **별도 동의**
- 제4항: (광고) 표기 + 전송자 명칭·연락처 + **무료** 수신거부·철회 수단 명시 (시행령 제61~62조)
- 제5항: 수신거부·철회 방해 금지
- 거래관계 예외: 재화 거래로 직접 연락처 수집 + **6개월 이내 + 동종 재화**면 사전동의 면제 (무료 응모·단순 이벤트 참여는 "거래" 아님)
- 정보성(거래정보) 정의(방통위 안내서): 이전 거래를 용이하게·완성·확인하거나, 구매·사용한 재화의 보증·리콜·안전 정보 → 동의 없이 가능
- **혼합 주의**: 정보성에 광고 문구가 일부라도 섞이면 전체가 광고성
- 위반 과태료: 최대 3,000만원 수준
- 출처: 국가법령정보센터 정통망법 제50조 · 방통위/KISA 「불법스팸 방지를 위한 정보통신망법 안내서」(제7차 개정본, 2026.03)

## 전자상거래 등에서의 소비자보호법 — 판매 페이지 표시의무
- 통신판매 광고 필수 표시: 상호·대표자·주소·연락처·사업자등록번호·**통신판매업 신고번호**, 가격·배송비·배송기간·교환/반품, **청약철회(수령 후 7일)**
- 표시·광고 내용과 다르면 공급받은 날부터 3개월/안 날부터 30일 내 청약철회
- 거짓 정보 제공 시 1천만원 이하 벌금
- 출처: 국가법령정보센터 전자상거래법 · 「전자상거래 소비자보호 지침」

## 개인정보보호법 제22조 (동의를 받는 방법) — 전송 대상 자격
- 각 동의사항을 **구분하여** 받아야 함. 마케팅/광고 수신 동의는 **필수와 분리된 "선택"**
- 필수에 끼워넣거나 강제 → 최대 1,000만원 과태료
- 채널별(SMS·이메일·앱푸시 등) 수신 동의는 세분화 관리 권장
- 빈칸 = 미동의(기록 없음). 입증 책임은 보내는 쪽
- 출처: 국가법령정보센터 개인정보보호법 제22조
