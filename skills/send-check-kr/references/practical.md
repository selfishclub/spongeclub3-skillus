# 실무 모드 — 고쳐주고, 써주고, 보내는 것까지

> 판정만으로 끝내지 않는다. 사용자가 실제로 다음 행동을 할 수 있게 만든다.
> 공통 원칙: 규정은 지키되 **소구는 살린다.** 밋밋하게 만드는 건 실패다.

## 1. 리라이트 — 위험 문구를 안전한 카피로

위험 판정이 나오면 반드시 **살아있는 대체 문구**를 같이 준다. 자주 쓰는 치환:

| 위험 (왜) | 안전하게 |
|---|---|
| "면역력 강화·감기 예방" (식품 효능) | "비타민C 가득한 제철" · "새콤달콤" · "지금이 제철" (성분·상태 사실) |
| "국내 1위·최초·100%" (실증 없는 최상급) | 근거 있으면 출처 표기, 없으면 삭제하고 구체 사실로("3대째 농사") |
| "정가 31,000원 → 0원" (부풀린 정가 의심) | 실제 판매가 기준으로 "3kg 무료 증정" 처럼 사실만 |
| "지금 사세요! 할인"이 알림톡에 섞임 (광고성) | 알림톡엔 정보성만 남기고, 판매·할인은 브랜드메시지/문자로 분리 |

리라이트 후엔 "이 버전은 🟢/🟡 어느 등급"인지도 한 줄 붙인다.

## 2. 통과 템플릿 작성 — 목적만 받으면 완성 문구

사용자가 "○○ 알림톡/문자 써줘" 하면, 목적을 확인하고 바로 템플릿을 준다.

**알림톡(정보성) 골격** — 첫 줄에 발송 계기 고정문구, 광고 문구 없음, 변수 최소:
```
[브랜드] (응모하신/주문하신/예약하신) (안내 제목)
(○○에서 ○○하신) #{성함}님, (정보성 안내).
(필요 시 거래 관련 정보 수집: 배송지 등)
[브랜드] 드림.
```
자세한 통과 규칙·반려 대응은 `alimtalk-review.md`.

**광고성(문자/브랜드메시지) 골격** — 동의자/채널 친구 대상:
```
(광고)[브랜드] (혜택·오퍼 한 줄)
(구매 유도 + 링크)
무료수신거부 (번호/방법)
```
→ 발송 시간 08:00~20:50(카카오)·야간 21~08(정통망법) 지킨다. 정보성/광고성 두 버전이 필요하면 나눠서 준다.

## 3. 채널 라우팅 — "이거 어디로 보내?"

메시지 성격 × 대상으로 채널을 정한다. (매트릭스는 `channels.md`)

- **정보성**(접수·배송·발표) → 알림톡 ⭕ (전화번호만 있으면 전원)
- **광고성**(사세요·할인) → 알림톡 ✕. **채널 친구면 브랜드메시지**, **마케팅 동의자면 문자**
- 대상이 **무료 응모자(미동의)** → 광고 못 보냄 → "채널 추가/재동의 받는 경로부터" 안내
- 답: **"이건 ○○로 보내세요. 이유는 △△. 조건은 (동의/표기/시간)."** 형식으로 짧게.

## 4. 발송 전 최종 체크리스트

실제 보내기 직전, 딱 이것만 원클릭으로:
```
□ 대상이 (광고면) 마케팅 동의자인가  (빈칸=미동의)
□ (광고) 표기 들어갔나
□ 무료 수신거부 방법 있나
□ 발송 시간 — 광고 야간 금지 (정통망법 21~08 / 카카오 08:00~20:50)
□ 업종 표현 점검 — 식품 효능·주류 권장 등 없나
□ (판매 페이지면) 통신판매 신고번호·청약철회 표시 있나
□ 알림톡이면 — 광고 문구 안 섞였나 / 발송 계기 고정문구 있나
```
정보성 메시지면 동의·야간·(광고) 항목은 건너뛴다고 알려준다.
