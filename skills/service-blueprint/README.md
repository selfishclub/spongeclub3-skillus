# Service Blueprint — 단계적 서비스 기획 스킬

아이디어 한 줄을 **투자·개발·디자인에 넘길 수 있는 산출물까지 단계적으로** 끌고 가는 Claude 스킬입니다. 한 번에 완성된 기획서를 토해내는 대신, 대화하며 단계마다 결정을 굳혀 수렴합니다. 추상(가치) → 구체(기능) → 형태(IA·화면) 순으로 좁혀 갑니다.

## 무엇을 해주나요

아이디어나 키워드만 던져도, 아래 흐름으로 기획을 발전시킵니다.

**가치 정의 → 비즈니스 모델 → 경쟁 벤치마킹 → 타겟·페르소나 → 브랜딩(네이밍 + 클리어런스 체크) → 디자인 톤 → 서비스 구조 → 기능 정의 → IA(정보구조) → 와이어프레임 → 엑셀 정리 → 기술 도면 핸드오프**

전체를 처음부터 가이드받을 수도 있고("이 아이디어 기획해줘"), 특정 단계만 골라 쓸 수도 있습니다("IA 그려줘", "기능정의서 만들어줘").

## 작동 원칙

이 스킬의 정체성은 단계 목록보다 아래 원칙에 있습니다.

1. **결정을 강제한다** — 막연한 질문 대신 A/B/C 선택지 + 트레이드오프를 제시하고 고르게 합니다.
2. **솔직한 리스크를 항상 병기한다** — 좋은 점만 말하지 않고, 위험을 같이 짚습니다.
3. **MVP를 칼같이 가른다** — "지금 만들 것 / 나중 것"을 매 단계 분리합니다.
4. **미결정은 추천 기본값 + `[결정 필요]` 태그로 남긴다** — 진행을 멈추지 않으면서 정직함을 유지합니다.
5. **점진적으로 디벨롭한다** — 한 단계 굳히고, 피드백 받고, 다음으로.

추가로, **수익 모델을 추상적으로 두지 않습니다** — "누가, 무엇에, 어떻게 돈을 내는가"를 끝까지 구체화합니다.

## 설치 방법

### 방법 1 — `.skill` 파일로 바로 설치 (가장 쉬움)
`service-blueprint.skill` 파일을 Claude의 스킬 설정에서 업로드하면 됩니다.

### 방법 2 — 소스 폴더 사용
`service-blueprint/` 폴더(`SKILL.md` + `references/`)를 스킬 디렉터리에 넣습니다. 내용을 읽거나 수정하고 싶을 때 이 방식을 씁니다.

## 사용 예시

```
"반려동물 산책 매칭 서비스를 기획하고 싶어"   → 가치 정의부터 전체 가이드
"우리 서비스 기능정의서 만들어줘"             → 기능 정의 단계로 바로 진입
"경쟁 서비스 좀 벤치마킹해줘"                 → 벤치마킹 단계
"이 아이디어 IA 구조도 그려줘"               → IA 단계
```

## 폴더 구조

```
service-blueprint/
├── SKILL.md                      # 스킬 본문 (원칙 · 단계 · 운영 모드)
└── references/
    ├── stages.md                 # 단계별 입력·핵심 결정·산출물 상세
    └── output-formats.md         # 기능정의서·IA·와이어프레임·엑셀 표준 양식
service-blueprint.skill           # 설치용 패키지
```
