# 14항목 크리틱 루브릭 — 무엇을 어떻게 보나

각 항목마다 **볼 것 → 위반 신호 → 수정 방향**. 점수는 5점 척도(●●●●● = 최상). 후킹 진단이 척추라면 이 14개는 갈비뼈다.

> **비주얼 항목(⑤⑥⑨⑩⑬)은 [visual-inspection.md](visual-inspection.md)의 5렌즈(AI 티·컨셉 정합·차별화·후킹·레이아웃)로 이미지를 한 장씩 확대해 판정한다.** 아래는 요약.

---

### ① 빅 아이디어 명료성
- **볼 것:** 캠페인을 관통하는 한 문장 컨셉이 서는가. 세 상품·여러 장표가 하나의 목소리인가.
- **위반 신호:** 장표마다 메시지가 따로 논다 / 컨셉이 슬로건 수준에 그침 / "그래서 한마디로?"에 답 못 함.
- **수정:** 한 문장으로 컨셉 재정의 → 모든 장표가 그 문장의 변주가 되게.

### ② 카피 후킹력 (첫 3초·말맛)
- **볼 것:** 첫 장/헤드라인이 3초 안에 꽂히나. 라임·대구·반전·언어유희 같은 말맛이 있나.
- **위반 신호:** PPT 텍스트처럼 밋밋 / 설명형 문장 / 후킹만 있고 가치 없음(낚시).
- **수정:** → [[훅카피]]로 서로 다른 기법 후보 뽑아 교체.

### ③ 메시지 위계
- **볼 것:** 한 장에서 핵심이 먼저 읽히나. 크기·위치·색으로 우선순위가 보이나.
- **위반 신호:** 다 같은 크기 / 핵심이 구석 / 정보 과밀.
- **수정:** 핵심 1개만 키우고 나머지 눌러 위계 재설계.

### ④ 타겟 적합성
- **볼 것:** 타겟의 언어·인사이트에 맞나. 그 사람이 "내 얘기"라 느끼나.
- **위반 신호:** 만드는 사람 언어 / 일반론 인사이트 / 타겟과 톤 불일치.
- **수정:** 타겟 실제 발화·상황으로 카피와 예시 교체.

### ⑤ 비주얼 컨셉 강도
- **볼 것:** KV가 컨셉을 **시각화**하나(설명 말고). 오브제·타이포·구도에 아이디어가 있나.
- **위반 신호:** 스톡 이미지풍 / 컨셉을 글자로만 얹음 / 1차원 직역.
- **수정:** → [[컨셉추얼KV]] 기준으로 그래픽 은유·오브제 위트 재설계.

### ⑥ 이미지 완성도 (해상도·AI티·왜곡)
- **볼 것:** 해상도 충분한가(용도별). 손·글자·얼굴 왜곡, AI 특유의 뭉갬·필름 없나.
- **위반 신호:** 저해상도 캡쳐 / 손가락 6개 / 한글 깨짐 / 플라스틱 피부.
- **수정:** 고해상도 재생성/업스케일, gpt_image_2로 한글 렌더, 원본 소스 사용.

### ⑦ 톤&매너 일관성
- **볼 것:** 팔레트·타이포·여백이 전 장표에서 일관되나. 브랜드 보이스 유지되나.
- **위반 신호:** 장표마다 폰트·색 제각각 / 캡쳐 슬라이드가 이질적.
- **수정:** 디자인 토큰(색·폰트·간격) 통일, 이질 슬라이드 새 양식으로 재구성.

### ⑧ 스토리 흐름 (첫장~끝장)
- **볼 것:** 기승전결이 있나. 도입 훅 → 전개 → 클라이맥스 → 엔딩이 이어지나.
- **위반 신호:** 클라이맥스 없음 / 같은 얘기 반복 / 엔딩이 흐지부지.
- **수정:** 장 순서 재배치, 중복 합치기, 엔딩에 선언형 한 방.

### ⑨ 차별화 (클리셰 회피)
- **볼 것:** 경쟁사·업종 클리셰를 피했나. 신선한가.
- **위반 신호:** "믿음·행복·함께" 뻔한 단어 / 남들도 쓰는 비주얼.
- **수정:** 업종 클리셰 리스트업 후 반대로 틀기.

### ⑩ 카피–비주얼 정합
- **볼 것:** 말과 그림이 같은 방향인가. 카피가 비주얼을 살리나(반대도).
- **위반 신호:** 카피 따로 이미지 따로 / 서로 힘 뺌.
- **수정:** 카피의 핵심 은유를 비주얼로, 혹은 반대로 맞물리게.

### ⑪ 설득력 / CTA
- **볼 것:** 행동을 유도하나. 근거(데이터·사례)가 주장 뒤에 있나.
- **위반 신호:** 주장만 있고 근거 없음 / 다음 행동 불명확.
- **수정:** 근거 붙이고, 명확한 다음 스텝 제시.

### ⑫ 제품 원화 충실도 (Product Lock)
- **볼 것:** 제품 KV에서 실제 제품의 **형태·비율·로고·원화**가 그대로인가.
- **위반 신호:** 병 형태·로고가 시안마다 다름 / 재해석된 로고.
- **수정:** → [[컨셉추얼KV]] Product Lock — 원화 레퍼런스 물려 재생성.

### ⑬ 디테일 마감 & 레이아웃
- **볼 것:** 정렬·그리드, 여백 리듬, 시각 위계, 시선 흐름(Z/F), 안전영역, 비율 왜곡·크롭 잘림, 텍스트 대비, 시리즈 일관성, 오타·페이지번호. (→ visual-inspection 렌즈 5)
- **위반 신호:** 요소 삐뚤·격자 안 맞음 / 이미지 crop으로 핵심 잘림 or 가로세로 늘어짐 / 배경에 글자 묻힘 / 위계 없이 다 같은 크기 / 오타.
- **수정:** 그리드 재정렬, 간격 토큰 통일, contain 처리, 스크림 추가, 안전영역 확보, 교정 1회전.

### ⑭ 실현성 / 과장 리스크
- **볼 것:** 규제 업종 확정 어구 지켰나. 근거 없는 수치·과장 없나.
- **위반 신호:** 미확인 KPI 단언 / 금융·의료 과장 표현.
- **수정:** `[확인 필요]` 표기, 확정 어구로 교체, 근거 자료 링크.

## 점수 → 평결 가이드
- 85+ : 통과. 디테일만 다듬으면 됨.
- 70~84 : 조건부. 후킹 1~2군데 손보면 살아남.
- 55~69 : 재작업. 컨셉은 있으나 실행이 안 따라옴.
- ~54 : 컷. 빅아이디어부터 다시.
