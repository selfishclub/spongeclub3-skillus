# 후킹 검증 체크리스트 (hook-checklist.md)

후보 카피를 거르는 관문. 각 후보를 6개 기준으로 통과/탈락시킨다. **하나라도 치명적으로 걸리면 버리거나 고친다.** 특히 1번(낚시)은 무조건 탈락.

---

## 1. 가치 부합 — 후킹 뒤에 알맹이가 있나? (치명)
- 이 카피가 끄는 시선을, 제품의 진짜 가치·USP가 받쳐주는가?
- 자극·재미만 있고 제품과 안 이어지면 → **낚시. 무조건 탈락.**
- 테스트: "그래서 뭐?"라고 물었을 때 답이 제품 가치로 이어지나?

## 2. 3초 테스트 — 3초 안에 꽂히나?
- 처음 보는 사람이 3초 안에 무슨 말인지 잡히는가?
- 두 번 읽어야 이해되면 → 감점. 수식어를 덜어낸다.

## 3. 기억성 — 다음 날 기억나나?
- 하루 뒤에도 입에 남거나 떠오르는가?
- 밋밋해서 스쳐 지나가면 → 기법을 더 세게(반전·라임·의외).

## 4. 타겟 언어 — 이 타겟이 실제로 쓰는 말인가?
- 타겟 연령·상황의 언어 습관에 맞나? (2030 vs 4050, 공공 vs 커머스)
- 너무 올드하거나 너무 힙해서 겉돌지 않나?

## 5. 브랜드 톤 부합 — 이 브랜드가 할 법한 말인가?
- 브랜드 무드·격과 어울리나? (럭셔리인데 너무 가볍거나, 공공인데 너무 튀거나)
- 톤이 어긋나면 후킹돼도 안 쓴다.

## 6. 리스크 스캔 — 사고 날 여지 없나?
- 발음 어려움 / 중의적 오해 / 비속어·타 언어 부정적 뜻 / 타 브랜드와 겹침 / 규제(공공·금융·의료) 소지.
- 걸리면 추천 시 **리스크로 명시**하거나 고친다.

---

## 판정 규칙
- **1번 탈락** → 즉시 버림 (낚시).
- **2·3번 약함** → 기법을 더 강하게 다시 뽑음.
- **4·5번 어긋남** → 톤·언어 교체.
- **6번 걸림** → 리스크로 표기하고 사용자 판단에 맡김.

통과한 후보만 Top 3 추천 후보로 올린다. 추천 시 각 후보의 남은 리스크(6번)를 솔직하게 병기한다.
