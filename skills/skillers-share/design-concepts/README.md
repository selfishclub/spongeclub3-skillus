# 디자인 컨셉 시안

공유회 덱의 디자인 방향을 잡기 위해 만든 시안이다. 아직 `references/themes.md` 의 정식 테마로는 안 들어갔다.

## 보는 법

브라우저로 HTML 파일을 바로 열면 된다. 한글이 깨지면 로컬 서버로 띄운다.

```bash
python3 serve.py    # http://localhost:8931
```

`python3 -m http.server` 를 쓰면 charset 헤더가 없어 한글이 깨진다. `serve.py` 는 그것만 붙여준다.

## 파일

| 파일 | 내용 | 판정 |
|---|---|---|
| `01-레퍼런스-5종.html` | 무드보드 프로젝트 5개에서 감도를 뽑은 표지+내지 | **표지 3개가 비주얼 0개.** 색만 바꾼 텍스트 슬라이드 |
| `02-비주얼-표지-5종.html` | 카피 위치를 전부 다르게, 컨셉에 맞는 비주얼 추가 | 07·08·09는 살아 있음. 06·10은 평범 |
| `03-질감-표지8-내지8.html` | 질감·실험 타이포 적용. **내지를 8종류로 쪼갬** | 현재 최신. 여기서 고르면 된다 |

## 어떻게 여기까지 왔나

**1차(01)의 실패** — 무드보드를 제대로 안 보고 색만 바꿨다. 표지 3개는 도형이 0개였다.

**2차(02)의 실패** — 비주얼은 넣었지만 **내지 10장이 전부 "제목 + 3열 나열"** 이었다. `themes.md` 의 「절대 금지 — PPT 티」 첫 줄을 스스로 어긴 것.

**3차(03)에서 고친 것**
- 무드보드 "시디"에 마스킹테이프·플라스틱랩·그레이니 글로우 텍스처가 잔뜩 있는데 1·2차는 전부 매끈한 평면이었다 → **전 화면 그레인**
- "Wed design"은 Inktrap·Liquid 같은 실험 폰트 중심 → **타이포를 그래픽으로**(마스킹·아웃라인·세로쓰기·잘림)
- **내지를 8종류로 분리** — 한 장 한 메시지 / 숫자 / 인용 / 전후 / 데모 전환 / 흐름 / 목록 / 클로징

## 03 구성

**표지 8** — A 타이포 마스킹 · B 테이프 콜라주 · C 하프톤 스캔 · D 아웃라인 스택 · E 세로 조판 · F 그리드 이탈 · G 에디토리얼 룰 · H 슬라이스

**내지 8** — i1 한 장 한 메시지 · i2 숫자 한 장 · i3 인용 · i4 전후 비교 · i5 데모 전환 · i6 흐름 · i7 목록(가로줄) · i8 클로징

표지 하나에 내지 여러 종류를 섞어 쓰는 게 실제 발표 방식이다.

## 적용된 규칙

- **명조체(세리프)를 쓰지 않는다.** 카피는 전부 고딕(Pretendard / Archivo Black)
- 라벨·넘버링만 모노(JetBrains Mono)
- 한글 행간은 `.98` 이상 — `.86` 이면 받침이 다음 줄에 닿는다
- 한글 자간은 `-.035em` 안팎 — `-.05em` 이면 받침 많은 글자가 뭉갠다
- 부제 대비는 **4.5 이상**(WCAG). 측정으로만 잡히는 실패가 많다
- `<!doctype html>` 필수 — 없으면 쿼크 모드에서 클래스 대소문자가 무시돼 `.f` 와 `.F` 가 충돌한다
