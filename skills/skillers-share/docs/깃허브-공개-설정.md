# 깃허브에서 남이 찾을 수 있게 (5분, 한 번만)

레포는 이미 Public 이고 MIT 라이선스도 있다. 남은 건 **검색에 걸리게 하는 것** 뿐이다.

## 1. 설명 넣기

github.com/Koo-bon/skillers-share → 우측 상단 **⚙ (About 옆 톱니)** 클릭

**Description** 에 붙여넣기:

```
1시간 발표를 주제 선정부터 웹 슬라이드·발표 대본까지 만들어주는 클로드 스킬
```

**Website** 는 비워둬도 된다.

## 2. 토픽 넣기

같은 창의 **Topics** 에 하나씩 입력 (엔터로 구분):

```
claude
claude-code
claude-skill
presentation
slides
korean
ai-agent
```

토픽이 있어야 `github.com/topics/claude-skill` 같은 목록에 뜬다.

## 3. 저장

**Save changes** 누르면 끝.

## 채널에 올릴 때

스킬러스 채널 `/스킬등록` 에 올릴 문구:

```
공유회-OS — 1시간 발표를 주제 선정부터 발표 대본까지 만들어주는 스킬

주제가 막막해도 됩니다. 대화 기록을 훑어 발표거리 후보를 먼저 깔아줍니다.
질문 3개 → 제목 → 목차 → 웹 슬라이드 → 발표 대본 → 검수까지.
발표자 노트(S)·구간 타이머(T)가 슬라이드에 내장돼 있고,
deploy.sh 한 줄이면 인터넷 주소가 나옵니다.

전: 구성·디자인 정하느라 발표 연습을 못 함
후: 질문 3개 답하고 덱까지

github.com/Koo-bon/skillers-share
```
