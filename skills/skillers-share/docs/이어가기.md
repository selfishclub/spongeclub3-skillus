```bash

# ③ 직접
git clone https://github.com/Koo-bon/skillers-share.git && cd skillers-share && bash install.sh
```
claude.ai(웹·앱·폰): 위 릴리스 zip 받아 **설정→사용자 지정→스킬→추가→스킬 업로드**에 드래그(1회).

**이어서 개발하려면 (작업)**
```bash
git clone https://github.com/Koo-bon/skillers-share.git
cd skillers-share
bash verify.sh                          # 잘 붙었는지 검사(PASS)
bash make-cloud-package.sh              # claude.ai zip 다시 빌드 → dist/
bash promo/build.sh                     # 홍보덱 리빌드 → promo/out/
# 고친 뒤: git add -A && git commit && git push
```

- `git` 이 없다고 나오면 맥은 `xcode-select --install` (몇 분)
- **고치는 건** 이 클론 폴더에서. 고친 뒤 `bash install.sh --force` 로 다시 깔고 테스트합니다
- 커밋은 `git add -A && git commit && git push`
