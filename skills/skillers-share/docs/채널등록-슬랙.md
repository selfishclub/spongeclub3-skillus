# 슬랙 스킬 등록용 (짧게)

🎤 **공유회-OS** — 1시간 발표를 주제부터 발표 대본까지

주제 막막해도 OK. 대화 기록 훑어 발표거리부터 깔아줍니다.
질문 3개 → 제목 → 목차 → 웹 슬라이드 → 발표 대본 → 검수.
발표자 노트·타이머 내장 · 인터넷 링크로 바로 공유.

💡 Claude Code(터미널)에서 제일 완전해요(기록 자동 스캔·인터넷 배포까지). claude.ai 웹·앱에서도 제한 모드로 가능(스캔·자동배포는 빠지고 주제 직접 입력·HTML 파일로).

**설치**
· 터미널(Claude Code): 이 링크 붙여넣고 "이거 설치해줘" → 끝
  `https://github.com/Koo-bon/skillers-share`
  (또는 한 줄: `curl -fsSL https://raw.githubusercontent.com/Koo-bon/skillers-share/main/install.sh | bash`)
· claude.ai 웹·앱·폰: [릴리스 zip](https://github.com/Koo-bon/skillers-share/releases/latest/download/skillers-share-claude-ai.zip) 받아 설정→사용자 지정→스킬→추가→스킬 업로드에 드래그 (1회, claude.ai는 채팅 링크 설치를 지원 안 해서 업로드만 됨)
**호출**: `공유회 준비해줘`
