# smartstore-analyze-collect

**한 줄:** 네이버 스마트스토어 주소 하나로 화면을 돌며 진단 증거(구조+캡처)를 모아주는 스킬 (파일 하나로 끝)

## 어떤 스킬인가요
스마트스토어 주소를 던지면 홈·목록·상세·쇼핑스토리를 순서대로 돌면서 팝업을 닫고, 접힌 상세정보를 펼치고, 구조(DOM)와 전체 페이지 캡처를 뽑아주는 스킬이에요. 채점은 안 해요 - 증거만 파일로 남겨요. 88줄짜리 채점 기준표와 추출 스크립트를 이 SKILL.md 파일 끝에 부록으로 통째로 묶어놓아서, 따로 받을 파일이 없어요. 파일 하나로 완전히 돌아가요.

## 뭘 해주나
주소 하나 주면 갈래(일반/브랜드스토어) 판별부터 상품 2개 상세까지 알아서 돌면서 사례 폴더에 메타.json·증거.json·shots/ 로 정리해줘요. 문서 끝 부록 A에 88줄 채점 기준표, 부록 B에 실제 추출 스크립트가 문자 그대로 들어있어요. 파일 하나 복사하면 진짜 끝이에요. 다른 업종이면 부록 A만 자기 기준으로 바꿔서 쓰면 돼요.

## 더 하고 싶은 말
이전에 한 번 올렸는데 번들 참고파일(추출기.js · 리포트_판정기준표.md) 두 개가 이 사이트의 등록 방식상(SKILL.md 한 파일만 가져감) 저장소에 안 실렸어요. 그래서 둘 다 한 파일 안에 부록으로 집어넣어 다시 올려요. 같은 이름으로 다시 올리는 거라 기존 폴더가 덮어쓰일 수도 있어요 - 덮어쓰이면 기존 버전(부록 없는 버전)은 지워주셔도 돼요. 새 버전이 파일 하나로 완전합니다.
