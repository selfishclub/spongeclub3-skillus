### 정숙(정동근) · 찜(아직 안 써봄)
- 쓴 상황: 스마트스토어 주소를 던지면 홈·목록·상세·쇼핑스토리를 순서대로 돌면서 팝업을 닫고, 접힌 상세정보를 펼치고, 구조(DOM)와 전체 페이지 캡처를 뽑아주는 스킬이에요. 채점은 안 해요 - 증거만 파일로 남겨요. 기준표가 바뀔 때마다 스토어를 다시 긁을 필요가 없게 수집과 판정을 일부러 갈라놨어요.
- 뭘 해주나: 주소 하나 주면 갈래(일반/브랜드스토어) 판별부터 상품 2개 상세까지 알아서 돌면서 사례 폴더에 메타.json·증거.json·shots/ 로 정리해줘요. 88줄짜리 채점 기준표(리포트_판정기준표.md)랑 실제 추출 스크립트(추출기.js)를 통째로 같이 묶어놔서, 폴더 그대로 받으면 바로 돌아가요. 다른 업종이면 기준표만 자기 걸로 바꿔 쓰면 돼요.
- 더 하고 싶은 말: 「셀러들의쇼핑몰」 스토어 진단 프로모션 만들면서 쓰던 스킬 3종(수집·검수·작성) 중 수집만 떼어서 독립적으로 쓸 수 있게 정리했어요. 원본은 르무통·루리코리아·담헌 3개 실제 스토어를 진단하면서 기준표를 8판까지 고쳐가며 검증했어요. 수집과 판정을 갈라둔 이유는, 기준표를 고칠 때마다 스토어를 다시 긁으면 느리고 남의 서버에도 부담이라서예요 - 증거를 파일로 남겨두면 스토어 안 건드리고 몇 번이든 다시 채점할 수 있어요. 스마트스토어 셀러 상대로 뭔가 진단·컨설팅해주는 분들한테 맞을 것 같아요.

- 뭘 해주나: 주소 하나 주면 갈래(일반/브랜드스토어) 판별부터 상품 2개 상세까지 알아서 돌면서 사례 폴더에 메타.json·증거.json·shots/ 로 정리해줘요. 문서 끝 부록 A에 88줄 채점 기준표, 부록 B에 실제 추출 스크립트가 문자 그대로 들어있어요. 파일 하나 복사하면 진짜 끝이에요. 다른 업종이면 부록 A만 자기 기준으로 바꿔서 쓰면 돼요.
- 더 하고 싶은 말: 이전에 한 번 올렸는데 번들 참고파일(추출기.js · 리포트_판정기준표.md) 두 개가 이 사이트의 등록 방식상(SKILL.md 한 파일만 가져감) 저장소에 안 실렸어요. 그래서 둘 다 한 파일 안에 부록으로 집어넣어 다시 올려요. 같은 이름으로 다시 올리는 거라 기존 폴더가 덮어쓰일 수도 있어요 - 덮어쓰이면 기존 버전(부록 없는 버전)은 지워주셔도 돼요. 새 버전이 파일 하나로 완전합니다.
