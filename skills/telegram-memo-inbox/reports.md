# 사용 리포트 · 개선안 — telegram-memo-inbox

---

### 포비(이지선) · ⭐5/5
- 쓴 상황: 텔레그램 대화창 하나를 내 메모 인박스로 만들어주는 스킬이에요.

저는 강의 때문에 밖에 있는 시간이 긴데, 이상하게 좋은 생각은 꼭 운전 중이거나
강의 끝나고 나오는 길에 떠오르더라고요. 그때마다 카톡 나에게 보내기, 메모앱,
노트에 흩어놨는데 나중에 하나도 못 찾았어요.

그래서 봇한테 그냥 던지면 저장되게 만들었습니다. 앱 안 열고, 폴더 안 정하고,
제목 안 짓고요. 지금 감사일기용 하나 칼럼 글감용 하나 돌리고 있는데,
쌓인 글감이 실제로 홈페이지 연재 칼럼 재료가 되고 있어요.

중요한 설계가 하나 있는데, 이 봇은 클로드를 안 거칩니다. 웹훅이 직접 받아서
직접 저장해요. 처음엔 클로드 연동으로 했다가 세션 꺼져 있으면 저장이 안 돼서
새벽에 던진 게 다음날 없어진 적이 있거든요. 가끔 안 들어가면 그건 인박스가
아니라서 직통으로 바꿨습니다.
- 뭘 해주나: 봇 만드는 것부터 실제 저장 확인까지 처음부터 끝까지 같이 해줍니다.

1. 뭘 모을지 / 어디에 쌓을지 / 어떻게 분류할지 3가지를 먼저 정해요 (코드보다 먼저)
2. BotFather로 봇 만들고 토큰이랑 chat_id 받기 - 한 단계씩 되는지 확인하면서
3. 웹훅 서버 코드 2파일 만들어주기 (노션 연동 포함)
4. Vercel 배포하고 환경변수 넣고 웹훅 연결
5. 핑 보내면 퐁 오는지 / 진짜 저장되는지 / 노션에 들어갔는지 3개 확인할 때까지 안 끝냄

코드 몰라도 됩니다. 준비물은 텔레그램 계정이랑 Vercel 무료 계정이면 돼요.

"반드시 지킬 것 10가지"를 넣어놨는데 전부 제가 실제로 데인 거예요.
- 웹훅에서 에러 돌려줬더니 텔레그램이 같은 메시지 무한 재전송
- 노션 404 - DB에 integration '연결'을 안 해서였는데 토큰 문제인 줄 알고 한참 헤맴
- 노션에 출처를 영문으로 뒀더니 브라우저 번역기가 telegram을 '전보'로 바꿔서 보여줌
- 서버가 UTC라 밤에 쓴 글이 전날 날짜로 들어감
- 저장소 목록조회 남발해서 무료 한도 넘겼더니 계정 저장소가 통째로 차단됨
- 윈도우에서 curl로 한글 보내면 깨짐

이미 봇 만들어놓고 "답장을 안 해" "저장은 되는데 노션에 안 들어가" 할 때
고장 진단용으로도 씁니다.
- 더 하고 싶은 말: 접두어를 필수로 안 한 게 제일 중요했어요. 처음엔 '일기:' 꼭 붙이게 했는데
운전하면서 접두어 붙이는 게 마찰이라 2주 만에 안 쓰게 되더라고요.
지금은 아무 말이나 던지면 저장되고 접두어는 있으면 인식만 합니다. 정규식 한 줄
차이인데 수명이 달라졌어요.

그리고 회신에 "47번째 기록 저장!" 처럼 번호를 넣었는데, 쌓이는 게 눈에 보여야
계속 쓰게 되더라고요.

아직 안 해본 건 사진·음성 저장이랑 목적지를 구글 시트로 하는 버전이에요.
써보시고 개선안 있으면 알려주세요!
