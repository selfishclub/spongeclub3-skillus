# telegram-voice-stt

텔레그램에 **음성을 녹음해 보내면**, 내 맥(또는 맥미니)이 **자기 안에서 whisper.cpp로 받아써서**
"손으로 타이핑한 메시지처럼" 처리하는 Claude Code 셋업 스킬. **완전 오프라인·무료·프라이버시**.

- 받아쓰기는 **로컬**(whisper.cpp, ggml-small) — 음성을 클라우드로 안 보냄, API 비용 0
- 전사 텍스트를 **일반 메시지처럼** 흘려보내 → `#메모` 저장·일정 등록·브리핑 등 **기존 기능이 음성으로도 자동**
- ffmpeg가 텔레그램 음성(.oga/.opus) → 16kHz WAV 변환, `transcribe.sh` 한 줄

핵심 철학: **음성을 특별 케이스로 만들지 말고, 전사 후 텍스트를 기존 파이프라인에 그대로 태운다.**

자세한 셋업·문제해결은 `SKILL.md` 참고. (Claude Code 스킬로 바로 사용 가능)
