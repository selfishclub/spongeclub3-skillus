# 따라 해보기 — 가상 이벤트 한 건

> 아래 가게·숫자는 **설명용으로 만든 가상 예시**다.
> 이 예시의 흐름은 기본값이다. 자기 이벤트에서는 질문 순서나 글 세트 구성을 바꿔도 된다.

**설정** — 1인 수제청 공방. 가을 유자청을 처음으로 사전예약 받는다. 스레드 팔로워 약 200명.

---

## 1. 사용자가 요청한다

> 유자청 사전예약 글 좀 써줘

## 2. 단계부터 묻는다 (❶)

"사전예약 글"이라고 했지만 **지금 받고 있는지**는 모른다. 짐작하지 않고 묻는다.

```
어떤 글인지 먼저 맞출게요. 이벤트가 지금 어디까지 왔나요?

 A. 아이디어만 있어요 — 오퍼·스토어·폼이 아직 없음      → 수요 확인 글
 B. 다 만들었는데 아직 안 열었어요                     → 예고 글
 C. 지금 열려 있어요 — 신청·예약 받는 중               → 전환 글 세트
 D. 이벤트가 아니라 조회수·팔로워를 늘리고 싶어요       → 다른 글쓰기 스킬로 안내

알파벳 하나만 답해 주세요.
```

> 사용자: 스토어에 올려놨고 오늘부터 받아. C

## 3. 빈 칸만 묻는다 (❷)

```
받은 것: 사전예약 · 스토어로 받음 · 오늘 오픈
비어 있는 것 (이것만 알려주세요)
 1. 무엇을 얼마에? (용량 · 가격)
 2. 예약 마감일과 받는 날
 3. 배송비는 포함인가요?
 4. 할인 전 가격을 쓸 건가요? 쓴다면 그 가격에 판 적이 있나요?
 5. 누가 제일 반길까요? 한 줄이면 돼요
```

> 사용자: 500ml 2병 24,000원. 10/5 마감, 10/12부터 순서대로 발송. 배송비 3,000원 별도.
> 원래 가격은 따로 없어, 올해 처음 팔아. 타겟은 환절기에 따뜻한 차 챙기는 30~40대.

## 4. 받는 구조를 본다 (❸)

```
받는 구조 점검
 ✓ 조건 없음 (스토어에서 바로 예약)
 ✓ 가격 근거 — 줄긋기 없이 "2병 24,000원"으로 그대로 표기
 ✗ 배송비 3,000원 별도 — 글에 안 쓰면 결제 단계에서 멈춤 → 오퍼 칸에 한 줄로 명시
 ✗ 받는 날 — "10/12부터 순서대로"는 언제 받는지 흐릿함 → "10월 둘째 주부터 예약 순서대로"로

✗ 두 개를 이대로 고쳐서 쓸까요? (네 / 다르게 할게)
```

> 사용자: 네

## 5. 첫 칸 후보 세 개 (❹)

```
1) 타겟 상황 — 환절기만 되면 목이 칼칼해서 따뜻한 차를 찾게 되더라.
2) 지금이어야 하는 이유 — 유자는 11월 초면 끝나. 올해 담글 수 있는 양이 정해져 있어.
3) 문턱 — 예약만 해두면 둘째 주에 알아서 도착해.

추천: 2번 — 유자 철이 실제로 짧아서 급하게 굴지 않고도 "지금"의 이유가 선다.
```

> 사용자: 2번

## 6. 글 세트 (❺)

**① 런칭 글**

> 칸1
> 유자는 11월 초면 끝나.
> 올해 담글 수 있는 양도 딱 정해져 있고.

> 칸2
> 그래서 올해는 처음으로
> 담그기 전에 먼저 예약을 받아보기로 했어.

> 칸3
> 유자청 500ml 2병, 24,000원.
> 배송비는 3,000원 따로야.
> 10월 5일까지 예약받고, 둘째 주부터 예약 순서대로 보내.

> 칸4
> 예약은 아래 스레드 확인

**② 답글 링크 칸**

> [스토어 예약 링크]

**③ 붐업 글 (2~3일 뒤)** — 실제 반응이 생긴 뒤에 채운다

> 칸1 [실제로 받은 질문 그대로 — 예: 설탕 비율, 보관 기간]
> 칸2 [그 질문에 대한 답]
> 칸3 10월 5일까지 받아. 예약은 아래 스레드 확인

**④ 마감 글** — 필요한지 묻는다: "마감 이틀 전에 한 번 더 올릴까요?"

**⑤ 댓글 응대**

| 댓글 | 답 |
|---|---|
| 예약했어요 | 고마워. 둘째 주에 순서대로 바로 보낼게 |
| 어디서 예약해요? | 아래 스레드에 링크 있어 |
| 설탕 많이 들어가요? | [실제 배합을 확인해서 사실대로] |
| 비싸요 | 올해 처음 담그는 거라 이 값으로 먼저 받고 있어 |

**올리기 전에 채울 빈칸**
- 답글 칸 예약 링크
- 붐업 글의 실제 질문과 답
- 설탕 배합 답변

## 7. 올린 뒤 (❻)

- 저녁에 올리고 1시간 스하리 — 검색어는 「환절기」「목감기 차」처럼 상황 단어로
- 프로필 링크를 예약 페이지로 바꿔두기
- 예약 댓글엔 전부 답하기

## 8. 끝나고 (❼)

공방 폴더에 기록 파일을 만들어 남긴다 — 글별 조회·댓글·예약 수, 먹힌 훅, 규칙대로 했는데 안 된 것.
