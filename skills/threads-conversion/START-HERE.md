# threads-conversion — 이벤트 글로 신청을 받아내는 스킬

스레드에서 **이벤트·사전예약·모집·대기자 신청을 받고 싶은 1인 사업자**를 위한 스킬입니다.
조회수를 늘리는 글이 아니라, **읽은 사람이 실제로 신청하게 만드는 글**을 짭니다.

---

## 먼저 알아둘 것 — 정답이 아니라 출발점입니다

이 스킬의 규칙은 **실제 스레드에 이벤트 글을 올리고 반응을 보며 반복해서 맞았던 것**을 모은 겁니다.
팔로워 84명 계정이 광고비 없이 무료 증정 이벤트로 215명의 응모를 받았고, 그중 4분의 3이 스레드에서 들어온 사례가 바탕입니다.

하지만 계정 크기·업종·오퍼·타겟이 다르면 같은 규칙도 다르게 먹힙니다.
**첫 이벤트는 기본값대로 돌려보고, 내 이벤트에서 안 맞는 건 고치고, 새로 맞는 건 더해서 내 버전으로 키워 주세요.**
키우는 방법은 `SKILL.md` 맨 아래 「내 이벤트에 맞게 키우기」에 있습니다.

규칙마다 붙은 꼬리표로 근거의 세기를 볼 수 있습니다.

| 꼬리표 | 뜻 |
|---|---|
| `[숫자 확인]` | 실제 이벤트 수치로 뒷받침됨 |
| `[반복 확인]` | 여러 번 올려보며 같은 방향으로 맞았음 (수치로 따로 재진 않음) |
| `[안전장치]` | 성과가 아니라 법·신뢰를 지키는 규칙 |

---

## 이렇게 부르면 됩니다

```
이벤트 글 써줘
```
```
사전예약 받는 글 짜줘
```
```
오픈 전에 예고 글 올리고 싶어
```
```
이런 이벤트 할까 하는데 반응 보는 글 써줘
```
```
스레드에서 타겟 글 모아서 분석해줘
```

## 무엇을 해주나

| 이벤트가 지금 | 받는 글 |
|---|---|
| 아이디어만 있음 | **수요 확인 글** — "이런 거 어때?"로 반응 보기 + 답 정리해서 진행/수정/보류 판단 |
| 다 만들었고 오픈 전 | **예고 글** — 여는 날 몰리게 기대 쌓기 |
| 지금 신청 받는 중 | **전환 글 세트** — 런칭 글 · 답글 링크 칸 · 붐업 글 · (마감 글) · 댓글 응대 + 올린 뒤 1시간 할 일 |
| 타겟 말부터 보고 싶음 | **타겟 글 모아 읽기** — 브라우저 AI(예: Aside)에 붙여넣을 수집 프롬프트 완성본 + 모은 글 판정표 · 페르소나 비교 · 이벤트에 쓰는 법 |

전환 글을 쓰기 전에는 **받는 구조**(신청 칸 수 · 조건 개수 · 가격 표기 · 받는 날 · 배송비 · 동의)를 먼저 보고, 새는 곳이 있으면 글보다 그걸 먼저 고치자고 합니다.

## 무엇을 하지 않나

- 조회수·팔로워를 늘리는 일반 글은 쓰지 않습니다 → 글쓰기 스킬(`threads-writing` 등)
- 스레드를 대신 올리거나 댓글을 달지 않습니다
- 없는 후기·신청 수·정가를 만들지 않습니다
- 광고법·개인정보 판단을 대신하지 않습니다 → 관련 스킬이 있으면 넘깁니다
