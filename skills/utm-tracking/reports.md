# 사용 리포트 · 개선안 — utm-tracking

---

### 3기제프(4조) · ⭐1/5
- 쓴 상황: 인스타·스레드·QR을 동시에 돌릴 때 "이 사람 어디서 왔지"를 알게 해주는 스킬이에요. 코드 없이 UTM 링크표로 시작하는 길이랑, 내 도메인 단축 링크+대시보드까지 세우는 길 둘 다 있어요.
- 뭘 해주나: - 링크 놓을 자리를 전부 적게 하고, 자리마다 다른 링크를 만들어줘요 (utm 이름 규칙표 포함)
- 구글폼·노션 폼에 유입 경로가 자동으로 들어가게 하는 법 알려줘요
- 단축 링크는 302로만 만들고, 카톡·슬랙 미리보기 봇이랑 내 테스트는 안 세요
- 배포 전에 키 노출·오픈 리다이렉트·어드민 검색 노출 같은 보안 체크 9개 돌려요
- 매주 같은 표로 채널 성적표 뽑아요
- 더 하고 싶은 말: 이번 주에 Vercel+Supabase로 직접 세우면서 겪은 실패 4개(같은 링크 여러 채널, 봇 섞인 숫자, 키 노출, GA 안 잡힘)를 규칙으로 넣었어요. 코드 없는 A레벨은 제가 아직 안 써봐서, 써보신 분 후기 부탁드려요.
