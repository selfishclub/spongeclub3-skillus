# 영상 제작 방식 역설계

영상 링크를 받아 프레임을 직접 뽑아 보고, 화면에 남은 흔적으로 제작 툴과 공정을 추정함.
**Claude는 소리를 못 들음.** 오디오 관련 판단은 전부 간접 근거(자동자막 유무·자막 싱크·설명란)로 하고 "추정"이라고 표시할 것.

## 작성 규칙
- 한국어, 음슴체(~임/~됨/~필요함), 표 중심
- 툴 이름은 단정하지 말 것. 영상만으로 특정 툴을 확정할 수 있는 경우는 워터마크·고유 UI가 보일 때뿐임. 나머지는 **후보 + 근거 + 확신도(높음/중간/낮음)**
- 툴 시장은 빨리 바뀜. 후보 툴 최신 버전이 애매하면 WebSearch로 확인하고 확인 날짜를 적을 것

---

## 1단계 — 메타데이터 수집

브라우저 패널(`mcp__Claude_Browser__*`) 사용.

0. 사용자에게 "캡처하는 동안 브라우저 패널을 열어둘 것"을 한 줄로 알림 (패널이 가려지면 캡처가 멈춤)
1. `resize_window` 900×1600 (**768 미만 금지**: 모바일 UA로 바뀌어 m.youtube.com이 뜨고 자동재생이 안 됨)
2. URL로 `navigate` → 3초 대기
3. `scripts/frame-grid.js` 파일 내용을 Read해서 `javascript_tool`로 실행 → 함수 등록 (페이지 이동마다 다시 등록)
4. `__meta('<videoId>')` 실행 → 제목, 채널, 설명란, 길이, 해상도, 자막 트랙, 페이지 텍스트

| 확인할 것 | 의미 |
|---|---|
| `same: false` | SPA 이동으로 이전 영상 정보가 남은 것. 새로고침 후 재시도 |
| 페이지 텍스트의 `AI` 배지 | 업로더가 합성·변형 콘텐츠로 신고함 → AI 생성 확정 근거 |
| 자막 트랙 `ko:asr` | 음성이 있음 (내레이션·대사 존재). 내용은 못 받음 — timedtext API는 빈 응답(POT 토큰 필요) |
| 설명란 | 대본 요약·출처·사용 툴이 적혀 있는 경우 많음. 해시태그로 장르 파악 |
| `리믹스` 버튼 | 단순 UI 요소. 제작 근거 아님 |

## 2단계 — 프레임 추출 (콘택트시트)

`await __grid([t1,...,t9], 1.5)` → `computer screenshot` 1장에 프레임 9장이 시각 라벨과 함께 찍힘.

| 영상 길이 | 샘플링 |
|---|---|
| ~30초 | 2~2.5초 간격, 호출 2회 (18장) |
| ~3분 | 3초 간격 첫 30초 (훅 분석용) + 이후 6초 간격, 호출 4~5회 |
| 3분 초과 | 초반 30초 촘촘히 + 나머지 균등 36장 이내 |

**함정 (실제로 겪은 것)**
| 증상 | 원인 | 대처 |
|---|---|---|
| `HIDDEN` 반환 / 모든 칸이 같은 프레임 | **브라우저 패널이 화면에 안 보임** (visibilityState hidden → 크롬이 영상 프레임 갱신 중단). 재시도·예열로 안 고쳐짐 | 캡처 전에 사용자에게 "브라우저 패널을 열어두라"고 한 줄 요청. `__grid`가 자동 확인함 |
| `STALE` 반환 | 패널이 보이는데도 첫/끝 프레임 동일 | 한 번 재호출. 그래도 같으면 진짜 정지 화면 영상 → 픽셀 차이로 재확인 |
| 모든 칸이 같은 프레임 (패널 보임) | 일시정지 seek 방식이거나 배속 2.5 이상 | 1.5배속 재생 캡처만 사용 (스크립트 기본값) |
| `TrustedHTML` 오류 | YouTube Trusted Types 정책 | `innerHTML` 쓰지 말 것. `replaceChildren()`·`createElement` 사용 |
| 반환값 빈 문자열 | 재생 시작 실패 | 시작 시점을 1~2초 바꿔 재호출 |
| 45초 타임아웃 | 한 호출에 영상 55초 초과 | 구간을 나눠 호출 |
| 스크린샷 타임아웃 | 브라우저 액션을 병렬로 여러 개 보냄 | 스크린샷은 한 번에 하나씩 순차 실행 |
| `readyState 0` | video 요소를 DOM에서 옮김 | 새로고침. 요소는 절대 이동하지 말 것 |
| 영상 위 작은 흰 글씨가 캔버스엔 없음 | YouTube 자동자막 오버레이(DOM) | 영상에 박힌 자막과 구분할 것 |

추가로 `await __cuts(start, 30, 1.5)` 로 컷 전환 시점을 뽑아 평균 컷 길이를 계산함 (페이드 전환은 놓침. 김·연기·물처럼 화면 전체가 움직이는 영상은 오탐이 많으니 콘택트시트에서 인물 위치·소품 상태가 바뀌는 지점으로 교차 확인).

## 3단계 — 판별 체크리스트

프레임을 보면서 아래를 채움. 근거가 된 프레임 시각을 같이 적을 것.

### 3.1 화면 소스
| 신호 | 판정 |
|---|---|
| 손가락·글자·간판 텍스트 뭉개짐, 과하게 매끈한 털/피부, 물리적으로 이상한 동작, 매 컷 다른 조명인데 전부 영화 같은 톤 | AI 생성 |
| 사람처럼 행동하는 실사 동물, 같은 캐릭터가 여러 장면에 일관되게 등장 | AI + 캐릭터 레퍼런스(일관성 기능) |
| 장면마다 무관한 실사 컷, 워터마크 흔적 | 스톡 영상 (Pexels, Storyblocks 등) |
| 흔들림·노이즈·자연스러운 초점 이동 | 실촬영 |
| 평면 도형·아이콘·키네틱 타이포 | 모션그래픽 (After Effects, Canva, CapCut 템플릿) |
| 컷당 2~3초 + 카메라가 한 방향으로만 천천히 움직임 | 이미지 → 영상(i2v) 생성 클립을 잘라 씀 |
| 컷당 5초·8초·10초에 딱 맞음 | 영상 생성 툴의 기본 클립 길이 그대로 사용 |

### 3.2 생성 툴 흔적
| 흔적 | 후보 |
|---|---|
| 우측 하단/화면 중앙 이동 워터마크 | 워터마크 텍스트로 확정 (Sora, Kling, Hailuo, Pika 등 무료 플랜) |
| 대사와 입모양·효과음이 클립 안에서 같이 생성됨, 8초 단위 | Veo 3 계열 |
| 5초/10초 클립, 동물·인물 동작 자연스러움 | Kling, Hailuo, Seedance |
| 이미지 속 영문 텍스트 깔끔함 | GPT 이미지, Nano Banana(Gemini), Imagen, Ideogram |
| 강한 영화 톤·필름 그레인·일관된 아트디렉션 | Midjourney |
| 인물이 말할 때 입모양이 자막 화자와 맞음, 한 장소·같은 인물로 긴 대화 | 대사까지 생성하는 영상 모델(Veo 3, Kling 오디오 등) 또는 립싱크 툴(HeyGen, Hedra 등). 소리 없이 둘 구분 불가 |
| 흔적 없음 | "특정 불가"로 쓰고 용도별 대표 후보 2~3개만 제시 |

### 3.2-B 편집 툴 워터마크 (무료 플랜) — 보이면 확신도 높음
| 워터마크 | 툴 |
|---|---|
| `movavi` (좌하단 작은 로고) | Movavi Video Editor |
| `Filmora` / `Wondershare` | Filmora |
| `VLLO` / `KineMaster` / `InShot` / `VITA` | 모바일 편집 앱 |
| `CapCut` 엔딩 컷 | CapCut |
| 마지막 1~2초에 다른 스타일 카드("구독 좋아요", "화면 두번 톡톡") | 채널 공용 아웃트로 템플릿. 본편과 편집 툴이 다를 수 있음 |

### 3.3 텍스트·자막
| 형태 | 후보 |
|---|---|
| 화면 중앙에 2~5어절씩 끊어 나오는 흰 굵은 자막 + 그림자 | CapCut 자동 캡션, Vrew |
| 상단 고정 제목 바 + 검정 레터박스 + 중앙에 가로 영상 + 하단 채널명 | CapCut/Vrew 쇼츠 템플릿 (가로 소스를 세로로 재활용하는 레이아웃) |
| 단어 단위 하이라이트·팝 애니메이션 | CapCut, Submagic, Captions 앱 |
| 자막 없음 | 내레이션 없는 영상이거나 음악 영상 |

### 3.4 오디오 (간접 추정)
| 근거 | 추정 |
|---|---|
| `asr` 자막 있음 + 자막이 일정한 리듬으로 끊김 + 사람 얼굴 안 나옴 | TTS 내레이션 가능성 높음 (타입캐스트, ElevenLabs, 수퍼톤, CapCut TTS, 클로바더빙) |
| 캐릭터 대사가 짧고 감정 연기 | 본인 녹음 또는 감정 TTS. 판별 불가 → 사용자에게 들어보고 알려달라고 요청 |
| `자동 더빙` 배지 | YouTube 자체 다국어 더빙 기능. 제작 툴 근거 아님 |

### 3.5 구성·대본
| 항목 | 볼 것 |
|---|---|
| 훅 | 첫 2초 화면·자막 문구. 질문형/숫자형/반전형 |
| 구조 | 기승전결, 문제→원인→해결→반전, "OO 특" 공감 나열 등 |
| 컷 길이 | 평균 몇 초. 2초대면 리텐션형 편집 |
| 시리즈성 | 고정 제목 바·캐릭터·채널 워터마크 → 템플릿 반복 생산 구조 |
| 대본 출처 | 정보형이면 리서치 + LLM 대본화 가능성. 설명란에 대본이 거의 그대로 있으면 확률 높음 |

## 4단계 — 출력 형식

아래 순서 고정. 영상이 여러 개면 영상별로 1~5를 쓰고 마지막에 6 비교표.

```
## N번) <제목> — <채널> (<길이>)

### 1. 한 줄 정의
<장르> / <화면 소스> / <제작 난이도>

### 2. 관찰 결과
| 항목 | 관찰 | 근거 프레임 |
(포맷·해상도, 레이아웃, 화면 소스, 캐릭터 일관성, 컷 수·평균 길이, 자막 스타일, 오디오 추정, 구성)

### 3. 추정 제작 파이프라인
| 단계 | 할 일 | 툴 후보 (확신도) | 대안 |
(기획/대본 → 이미지 → 영상화 → 음성 → 편집·자막 → 업로드 순)

### 4. 재현 프롬프트 예시
- 캐릭터/스타일 고정 프롬프트 1개
- 컷 프롬프트 2~3개 (실제 프레임 장면 기준)
- 대본 생성 프롬프트 1개 (정보형일 때)

### 5. 제작 부담
| 항목 | 값 |
(컷 수, 예상 작업 시간, 유료 플랜 필요 여부, 병목 단계)

### 확인 못 한 것
- (음성 종류 등 판별 불가 항목과 확인 방법)
```

6. 비교표 (여러 영상일 때)
| 항목 | 1번 | 2번 |
