# 스킬 메이커

**한 줄:** 뭘 스킬로 만들지 막막할 때, 질문 10개 주고받으면서 스킬 하나 끝까지 만드는 스킬

## 어떤 스킬인가요
스킬 만들어 보라고 하면 다들 "뭘 만들지"에서 멈추더라고요. 저도 그랬고요.
그래서 클로드가 질문을 하나씩 던지고, 답하다 보면 스킬이 완성되게 만들었어요.
메모나 링크, 파일이 있으면 그거 들고 오면 되고, 아무것도 없어도 시작할 수 있어요.
질문은 10개 안 넘기고, 트리거나 프론트매터 같은 말은 안 써요.

## 뭘 해주나
"스킬 만들고 싶어"라고 하면 시작해요.
매주 반복하는 일 찾기 → 하나로 좁히기 → 뭘 넣고 뭘 받을지 → 당부할 것, 하면 안 되는 것 → 부르는 말 → 이름 순서로 물어봐요.
중간중간 "여기까지 이런 스킬이에요" 하고 표로 정리해 주고, 만들기 전에 초안을 한 번 보여줘요.
끝나면 설치, zip 파일, SKILL.md 원문, 한 장 설명서 중에 고른 것만 만들어 주고, 샘플로 한 번 돌려본 다음 고칠 거 있냐고 물어봐요.

## 더 하고 싶은 말
만들고 나서 클로드한테 요가 원장님, 쇼핑몰 사장님 역할을 시켜서 시험 운전을 두 번 해봤어요.
"질문 10개"라고 해놓고 실제로는 답을 19번 해야 했고, 첫 질문이 클로드를 써본 사람 기준이라 막히더라고요. 그런 데를 고쳐서 올려요.
진짜 사람이 써본 건 아직이라 어디서 막히는지 알려주시면 좋겠어요.
