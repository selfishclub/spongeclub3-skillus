# 크리틱디렉터 (critic-director)

> 아이디어 한 줄부터 완성된 제안서·KV·발표 덱까지 — **10년차 크리에이티브 디렉터의 눈으로 "이거 후킹하냐"를 판정하고 고쳐주는** Claude 스킬.

광고·브랜드 크리에이티브를 만들다 보면, 마지막에 "이대로 나가도 되나?"를 냉정하게 봐줄 사람이 필요합니다. 크리틱디렉터는 그 **최종 검수관** 역할을 합니다. 페르소나와 크리틱 강도를 골라, 후킹 진단 → 크리틱 → 수정안 → 승인한 것만 반영까지 한 바퀴 돕니다.

## 뭘 해주나요

- **두 모드** — ① 아이디어·컨셉만 던져도 후킹력·차별화·타겟 적합성으로 바로 크리틱, ② 완성된 제안서·KV·덱은 처음부터 끝까지 통으로 검수
- **페르소나 5종** — 10년차 크리에이티브 디렉터 / 기획자 / 타겟 소비자 / 분야 전문가 / 클라이언트(발주처)
- **크리틱 강도 1~4단계** — 순함(코칭) ~ 아주 매움(칸 심사위원, "이건 컷")
- **후킹 진단** — 후킹 점수·후킹 포인트·언후킹 지점·**발표 시 지루해지는 구간(주의 곡선)**·후킹업 수정안
- **비주얼 정밀 검수** — 이미지를 한 장씩 확대해 **AI 티·컨셉 정합·차별화·후킹·레이아웃** 5렌즈로 판정
- **14항목 스코어카드** + Top 우선 수정. **승인한 것만** 고칩니다(통제권 유지).

## 설치

### 방법 1 — 플러그인 마켓플레이스 (권장)
Claude Code에서:
```
/plugin marketplace add Koo-bon/critic-director
/plugin install critic-director
```

### 방법 2 — 수동 복사
```bash
git clone https://github.com/Koo-bon/critic-director.git
cp -r critic-director/critic-director-plugin/skills/크리틱디렉터 ~/.claude/skills/
```
다음 세션부터 자동 발동합니다.

## 써보기

```
"이 아이디어 크리틱해줘: 은행 앱을 '월급 지킴이'로 포지셔닝"
"이 제안서 검수해줘 — 클라이언트 눈으로, 아주 맵게"
"이 KV AI 티 나는지 봐줘"
```
발동하면 **페르소나·강도**를 먼저 물어봅니다.

## 참고

- 카피 수정은 `훅카피`, 비주얼 재생성은 `컨셉추얼KV` 스킬에 위임하도록 설계됐습니다. 이 두 스킬이 없어도 **크리틱과 구체 수정안 제시는 그대로 동작**합니다(같이 쓰면 수정 반영까지 자동화됩니다).
- 강도가 높아져도 근거 없는 인신공격은 하지 않습니다 — 항상 "왜 그런지 + 어떻게 고칠지"를 붙입니다.
